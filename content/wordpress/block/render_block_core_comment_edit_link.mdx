## Behaviour

Renders the Comment Edit Link block (core/comment-edit-link) on the server, from its attributes, inner content and context: displays a link to edit the comment in the WordPress Dashboard. This link is only visible to users with the edit comment capability. <Ev source="wp:wp-includes/blocks/comment-edit-link.php#L19-L49" hash="8848fa471021ee885e6fa145541b955e9cb90c75d7923d39c4e708da582dfc33"/>

## Override

Not overridable.
