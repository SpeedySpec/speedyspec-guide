## Behaviour

Renders the Home Link block (core/home-link) on the server, from its attributes, inner content and context: create a link that always points to the homepage of the site. Usually not necessary if there is already a site title link present in the header. <Ev source="wp:wp-includes/blocks/home-link.php#L107-L139" hash="45fb4d8933d021509f9f9e3fd3944c0c98f24d0042db0c23e3b4a77b9eb806a9"/>
