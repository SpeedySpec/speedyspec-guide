## Behaviour

Adds a skip-to-content link before the template's wp-site-blocks div, pointing at its main element (given an id when it has none); the HTML unchanged when either is missing. <Ev source="wp:wp-includes/block-template.php#L350-L400" hash="b123433bfe3f08c6abb4c3516b612e13946dd2ad07053a2cf329e38bd566b92c"/>
