## Behaviour

Records in a block's metadata the hooked blocks it already shows, so they aren't inserted twice. <Ev source="wp:wp-includes/blocks.php#L1094-L1136" hash="80cbd487c83f72270073aa4d468eab2743c624f25358dadff02fda73ec49c54d"/>

## Override

`hooked_block_types`, `hooked_block`, `hooked_block_{$hooked_block_type}` filter it.
