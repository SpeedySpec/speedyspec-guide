Parses HTML as the HTML standard's tree builder does, on top of `WP_HTML_Tag_Processor`: it tracks the open elements, so it knows each element's breadcrumbs, and it visits the elements and closers the HTML only implies (virtual tokens). It supports most HTML; on markup it doesn't support yet it stops, and `get_last_error()` says so, rather than guess.
