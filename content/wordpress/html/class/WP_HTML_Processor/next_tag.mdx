Moves to the next tag matching a query, and returns whether it found one. A query is a tag name, or an array with `tag_name`, `class_name`, `tag_closers`, or `breadcrumbs` (ancestors ending with the tag, `*` matching any) and `match_offset`. A string is a one-element breadcrumbs query. <Ev source="wp:wp-includes/html-api/class-wp-html-processor.php#L702-L780" hash="4c246610ef54cde50cac7516f31bab8a89db6c5a3265baf9c1c74e809b727a43"/>
