---
symbol: "method:WP_HTML_Processor::expects_closer"
---

Says whether the current token, or the given one, will have a closer: not text and other `#` tokens, not void elements, not elements whose contents are raw text such as `script` and `textarea`, and not self-closing foreign elements. It returns `null` when there is no token. <Ev source="wp:wp-includes/html-api/class-wp-html-processor.php#L994-L1016" hash="87d5fb32540cf92d8b12f9ad1a316c771778480732a1e68a8c70e4153b0356f2"/>
