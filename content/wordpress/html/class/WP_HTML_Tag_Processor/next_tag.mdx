Moves to the next tag matching a query, and returns whether it found one. The query is a tag name, or an array of `tag_name`, `class_name`, `match_offset` (the nth match) and `tag_closers` (`visit` to stop on closers too); with none, any opening tag matches. <Ev source="wp:wp-includes/html-api/class-wp-html-tag-processor.php#L912-L931" hash="aa60b9fb4e839b66ee7e86676ff9d9f4a43d47eb28395e2ddabdbb19a7c8a309"/>
