Sets an attribute on the current opening tag, and returns whether it could. `true` writes it without a value and `false` removes it. URL attributes such as `href` are escaped with `esc_url()`; others have `<`, `>`, `&`, `"` and `'` escaped. A name the standard doesn't allow, or a value that escaping empties, is refused. <Ev source="wp:wp-includes/html-api/class-wp-html-tag-processor.php#L4623-L4764" hash="344791019174ec59524e18cf9f3a18c1189b0cf3c852699150f4bdc2eed10220"/>
