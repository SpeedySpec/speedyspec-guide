Replaces the current token's text, escaping it as its context needs, and returns whether it could. Text nodes and `textarea` and `title` contents are HTML-escaped. `script` and `style` contents are refused when they would end the element early, and JavaScript in `script` is escaped so it can't. <Ev source="wp:wp-includes/html-api/class-wp-html-tag-processor.php#L3980-L4243" hash="3a74577298259259c7bc927b15be39041374e893e5d9cb3a843ec4ad205db6b1"/>
