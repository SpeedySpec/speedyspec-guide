Reads the character reference at a position, returning the text it stands for and its length, or `null` when there isn't one. Numeric references outside Unicode, or for surrogates, become the replacement character, and some C1 controls the character the standard maps them to. <Ev source="wp:wp-includes/html-api/class-wp-html-decoder.php#L258-L479" hash="46760d39916b80d99bd8b30b1530f8228940e8614887c704e8c94e1b16593167"/>
