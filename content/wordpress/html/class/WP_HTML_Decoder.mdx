Decodes character references, such as `&amp;` and `&#x263A;`, as the HTML standard does. The rules differ between text and attribute values: in an attribute, a named reference without `;` followed by a letter, digit or `=` stays as written. <Ev source="wp:wp-includes/html-api/class-wp-html-decoder.php#L12-L507" hash="21d77e5b0fc749039b93daf56da130eb6b82d5d863e5da1d0621dac44a999494"/>
