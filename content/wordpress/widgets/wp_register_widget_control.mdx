## Behaviour

Registers a widget's form callback by ID (250 wide by default), and its update callback by ID base unless one is set; an empty callback removes both. Before `widgets_init`, one already registered is kept. <Ev source="wp:wp-includes/widgets.php#L538-L587" hash="e75d1fee42859db2199ae2183498f480078d079cea105c04ff2768da74d44aa4"/>

## Override

Not overridable.
