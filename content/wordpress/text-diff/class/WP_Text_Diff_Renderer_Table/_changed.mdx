Prints a change. It pairs lines with `interleave_changed_lines()` and diffs each pair inline. If more than `_diff_threshold` (0.6) of a pair's text changed, the pair is shown without the inline marks. Lines left unpaired are printed as added or deleted rows. <Ev source="wp:wp-includes/class-wp-text-diff-renderer-table.php#L287-L370" hash="7cf212954f1766b48aac6c725f0c8e943f85c80c004dd621a3f6e7ed82b577ae"/>
