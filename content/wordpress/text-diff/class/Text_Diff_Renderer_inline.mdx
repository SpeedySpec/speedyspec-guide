Prints a diff with the changes marked inline: added text between `<ins>` and `</ins>`, deleted text between `<del>` and `</del>`, and every line HTML-escaped. It keeps all unchanged lines (10000 lines of context), and within a changed line it marks the words that changed. <Ev source="wp:wp-includes/Text/Diff/Renderer/inline.php#L27-L206" hash="a2353f37ccbaf216155c120d955e53e3bb307f30a3efc0d91f62b6bc0ecd4bc3"/>
