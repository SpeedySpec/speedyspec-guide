## Behaviour

Cleans a value for an option by its name: numbers for size and count options, `esc_html()` for the site title and tagline, URLs for `siteurl` and `home`, lists for keys, domains and ping sites, and so on. An invalid value is replaced with the option's current value and, in the admin, reported with `add_settings_error()`. <Ev source="wp:wp-includes/formatting.php#L4976-L5259" hash="091c923d845b80c419f182f51748ccbcd2b6c6b1e954610346d313830cec60e8"/>

## Override

`sanitize_option_{$option}` filters the result for every option.
