## Behaviour

Returns the allowed HTML for a context: `post` (`$allowedposttags`), `user_description` and `pre_user_description`, `strip` (nothing), `entities` (`$allowedentitynames`), `data` (`$allowedtags`), or an array given directly. Every element also gets the global attributes, such as `class`, `id`, `style` and `data-*`. <Ev source="wp:wp-includes/kses.php#L2143-L2213" hash="3cebedbc7af1e0872e67d269d36f0eab0dab34562b6a7cee9d72ee1208007c2e"/>

## Override

`wp_kses_allowed_html` filters the result for each context.
