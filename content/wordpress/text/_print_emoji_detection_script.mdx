## Behaviour

Prints the emoji settings as a JSON script (image and SVG URLs and extensions, and the script sources) and the emoji loader module. <Ev source="wp:wp-includes/formatting.php#L6092-L6163" hash="954e6d6195a32828ca33a850678de284854cb45d91226df2ea20810929632a7a"/>

## Override

`emoji_url`, `emoji_ext`, `emoji_svg_url`, `emoji_svg_ext` and `script_loader_src` filter the settings.
