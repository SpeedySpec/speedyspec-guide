## Behaviour

Returns the `rel` attribute for a link `make_clickable()` creates: `nofollow` for an http or https link off the site, plus `ugc` inside comment text. <Ev source="wp:wp-includes/formatting.php#L3162-L3192" hash="85c4f8dd2f7dfec3a816b6f64b4c649d56242822aef51ebeddf900cc84bab4f1"/>

## Override
