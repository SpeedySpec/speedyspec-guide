## Behaviour

Says whether a `data-wp-bind--<attribute>` directive would set an attribute whose values kses restricts, so it can't be allowed: the Interactivity API could otherwise set a value kses would refuse. <Ev source="wp:wp-includes/kses.php#L4312-L4348" hash="31a6ec3bd8e20ee611e205925f7a06ebd6692bddcb39b549fb66048dfdbdcacb"/>

## Override

Not overridable.
