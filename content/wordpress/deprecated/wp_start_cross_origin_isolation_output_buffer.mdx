## Behaviour

Deprecated in 7.2.0; use wp_send_document_isolation_policy_header(). Starts an output buffer that sends the Document-Isolation-Policy header and adds crossorigin="anonymous" to cross-origin resources. Calling it reports the deprecation (deprecated_function_run). <Ev source="wp:wp-includes/deprecated.php#L6688-L6692" hash="e1f6fae08e53ae74d420f05aa775798cfae419ffe21ba580976d0bf193358a1d"/>

## Override
