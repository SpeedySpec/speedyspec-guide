## Behaviour

Deprecated in 6.9.0; use wp_enqueue_img_auto_sizes_contain_css_fix. Prints a CSS rule to fix potential visual issues with images using `sizes=auto`. Calling it reports the deprecation (deprecated_function_run). <Ev source="wp:wp-includes/deprecated.php#L6524-L6536" hash="93135afb41175b27b2e693f242a9d141024aa8a89c5a5bd894e5c837d9ffa811"/>

## Override

`wp_img_tag_add_auto_sizes` filters it.
