## Behaviour

Deprecated in 5.9.1; use wp_get_duotone_filter_property(). Renders the duotone filter SVG and returns the CSS filter property to reference the rendered SVG. Calling it reports the deprecation (deprecated_function_run). <Ev source="wp:wp-includes/deprecated.php#L4292-L4296" hash="ff26dbf1036e49a7ed1cedc15ddb4ca153ac1aace3908146dd2036d48c83047e"/>
