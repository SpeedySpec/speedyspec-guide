An ability: a named, described unit of work with JSON schemas for its input and output, a permission check and a callback. `execute()` runs it through every check. A subclass can override `do_execute()` and the permission check, and then needs no callbacks. <Ev source="wp:wp-includes/abilities-api/class-wp-ability.php#L21-L1109" hash="4e790b5a6a2a220a6d43bb5aff14c824cd5ee4bcdef4655502340fac28417ed6"/>
