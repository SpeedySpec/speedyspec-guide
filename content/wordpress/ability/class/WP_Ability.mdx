An ability: a named, described unit of work with JSON schemas for its input and output, a permission check and a callback. `execute()` runs it through every check. A subclass can override `do_execute()` and the permission check, and then needs no callbacks. <Ev source="wp:wp-includes/abilities-api/class-wp-ability.php#L21-L1132" hash="bce20b2fa82ad761acb9a6e6b43f8c1c21853a62532122d700a86137f96c6dc1"/>
