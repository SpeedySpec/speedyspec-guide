Runs the query with `WP_User_Query`. A filter it can't honour is refused rather than dropped, so the query never widens: `where` that isn't an object, a list with no valid value left, `roles` or `usernames` without `list_users`, or an unusable `has_published_posts`. Without `list_users`, only authors of posts of publicly viewable types are listed. A page holds 10 users, or up to 100 when listing by IDs, slugs or usernames, unless `per_page` says otherwise.
