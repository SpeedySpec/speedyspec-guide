## Behaviour

Prints a trackback's XML answer with the site's charset as the content type: error 0 on success, or error 1 with the message, after which it ends the request. It is declared in `wp-trackback.php`. <Ev source="wp:wp-trackback.php#L33-L49" hash="79bc3cae1cf38fc8182c753c3d509e08fa25f15e9e1ddbda6f25e44c625b9906"/>

## Override

Not overridable.
