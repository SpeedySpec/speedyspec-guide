An SMTP client: it connects to a mail server, says hello, authenticates, and sends a message's envelope and data, one command at a time. `PHPMailer` uses it when sending by SMTP. It is part of PHPMailer 7.2.0, bundled with WordPress in `wp-includes/PHPMailer/`. <Ev source="wp:wp-includes/PHPMailer/SMTP.php#L31-L1671" hash="e692d0367fb8610a325888b500a141d241186aefd092aba97ad16ed22635c5f6"/>
