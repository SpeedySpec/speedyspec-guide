## Behaviour

Sets one of the current user's settings and saves them all with `wp_set_all_user_settings()`. Once headers are sent it returns `false`. <Ev source="wp:wp-includes/option.php#L1774-L1783" hash="8cf51b14ef90793b6fc283e2e321f5bf933f0b66424ba64033c309058f992c54"/>

## Override

Not overridable; it fires no hooks of its own.
