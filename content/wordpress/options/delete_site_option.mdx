## Behaviour

Deletes a network option of the current network: [`delete_network_option()`](/wordpress/options/delete_network_option/) with a `null` network id. On a single site that is an ordinary option. <Ev scenario="site_option_fallback" area="options"/>

## Override

The hooks are `delete_network_option()`'s.
