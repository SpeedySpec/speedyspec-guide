## Behaviour

Replaces `wp_admin_bar_header` on `wp_head` (or `admin_head`) with an inline style on `admin-bar` that hides the bar when printing; when it isn't hooked, it does nothing. <Ev source="wp:wp-includes/admin-bar.php#L1409-L1418" hash="b59bb328dc5c7d137b46f34055f192ceef56c391ae4d1639cd1d44e9722160a7"/>

## Override

Not overridable.
