## Behaviour

On the front end, adds the Customize link to open the current page in the Customizer, for a user with `customize`. A block theme without Customizer controls gets no link. <Ev source="wp:wp-includes/admin-bar.php#L563-L605" hash="fb33bfe84d99f9a31ba25dd834bca83c4f12d99f8bcbe63eeb412c7b50978698"/>

## Override
