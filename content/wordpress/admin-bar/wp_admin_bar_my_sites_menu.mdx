## Behaviour

On multisite, adds My Sites for a logged-in user with sites (or a network admin): the network admin links the user can use, then each of their sites with links to its dashboard, new post, comments and front end. <Ev source="wp:wp-includes/admin-bar.php#L614-L831" hash="42e0b420773bf030c52dac966d657b560b6b22d42891b7287174a5efca072fec"/>
