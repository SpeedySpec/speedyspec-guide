Adds a node, or updates the one with its id: the arguments merge into it, meta included. A node without an id but with a title gets one from the title, with a notice; one with neither is skipped. The old parents `my-account-with-avatar` and `my-blogs` become `my-account` and `my-sites`, with a notice. <Ev source="wp:wp-includes/class-wp-admin-bar.php#L130-L186" hash="93a902b4611d2c6c0f80509516dd49c3cdc169975f799c43faddd4be18314edb"/>
