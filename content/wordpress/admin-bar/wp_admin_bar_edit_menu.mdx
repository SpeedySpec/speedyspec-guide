## Behaviour

Adds the link between the front end and the admin for the current object. In the admin it links to view the post, the post type archive, the term or the author being edited (a draft gets a preview link). On the front end it links to edit the queried post, term or user, when the user may. <Ev source="wp:wp-includes/admin-bar.php#L874-L1005" hash="42d8160c31848653aa30f99ae1646f749aae6d8bde5dc9018c44d340ae4ced6d"/>

## Override

Not overridable.
