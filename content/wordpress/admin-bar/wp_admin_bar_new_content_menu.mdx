## Behaviour

Adds the New menu: a link for each post type shown in the admin bar that the user may create (posts, media, links and pages first), User for those who can create users, and Site on multisite. The menu links to the first. With none, nothing is added. <Ev source="wp:wp-includes/admin-bar.php#L1083-L1165" hash="2d62acfc7a0c296d5d8df806a5e5d1a6516c3cbbc2932c30b265526721dff621"/>

## Override

Not overridable.
