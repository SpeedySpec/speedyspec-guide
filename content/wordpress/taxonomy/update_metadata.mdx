## Behaviour

Updates an object's meta, adding it when missing; with a previous value, only rows with that value. Returns true, the new meta ID, or false when nothing changed. update_{$meta_type}_metadata can answer first; update_ and updated_{$meta_type}_meta fire. <Ev source="wp:wp-includes/meta.php#L196-L372" hash="7777fdbbd6498837a96d352fe7a68ac33d0e9e682e54cae18d973edc3489352b"/>

## Override

`update_{$meta_type}_metadata` filters it; `update_{$meta_type}_meta`, `update_postmeta`, `updated_{$meta_type}_meta`, `updated_postmeta` fire.
