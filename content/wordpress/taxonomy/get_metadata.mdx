## Behaviour

An object's meta: all keys, one key's values, or its first value with $single; a missing key gives the registered default ('' for single, an empty array otherwise). Values are unserialized. <Ev source="wp:wp-includes/meta.php#L622-L629" hash="5676176045c86436feb20d642273d4e84788af1489f8d75350868f016e53e389"/>
