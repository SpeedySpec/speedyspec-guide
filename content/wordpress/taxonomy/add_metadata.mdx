## Behaviour

Adds a meta value to an object; with $unique, refused when the key already has a value. Values are stored serialized when needed; add_{$meta_type}_metadata can answer first, and added_{$meta_type}_meta fires with the new meta ID. <Ev source="wp:wp-includes/meta.php#L40-L171" hash="7c448430b99a56a40bc0d62c72091c6894046e03e280a93acc8db3a8b4922b24"/>

## Override

`add_{$meta_type}_metadata` filters it; `add_{$meta_type}_meta`, `added_{$meta_type}_meta` fire.
