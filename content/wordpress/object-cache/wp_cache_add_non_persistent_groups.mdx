## Behaviour

Marks groups that a persistent cache should keep only for the request. The built-in cache keeps nothing between requests, so it does nothing. <Ev scenario="non_persistent_groups_noop" area="object-cache"/>

## Override

A persistent object cache drop-in (`wp-content/object-cache.php`) replaces the whole Object Cache API.
