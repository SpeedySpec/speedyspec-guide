## Behaviour

The CSS that paints the theme in its primary color: the chosen hue (199 by default) with the saturation and lightness filters, for the front end and the editor; twentynineteen_custom_colors_css filters it. <Ev source="wp:wp-content/themes/twentynineteen/inc/color-patterns.php#L13-L272" hash="fe0c8160d6d7fc11f1604e44fbc65d06223f6bb5abb2c49fdbe67817eeac2509"/>

## Override

`twentynineteen_custom_colors_saturation`, `twentynineteen_custom_colors_saturation_selection`, `twentynineteen_custom_colors_lightness`, `twentynineteen_custom_colors_lightness_hover`, `twentynineteen_custom_colors_lightness_selection`, `twentynineteen_custom_colors_css` filter it.
