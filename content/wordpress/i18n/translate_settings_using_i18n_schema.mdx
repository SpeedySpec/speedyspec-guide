## Behaviour

Translates the strings of a settings structure that a schema marks: an object schema names keys (or `*` for any), an array schema applies its first item to every element, and a string is the context. <Ev source="wp:wp-includes/l10n.php#L2153-L2183" hash="212b39efd1b40f5400bc5f82605923e8620f5e1a54b74e7a428d4e6b9f87cc5b"/>
