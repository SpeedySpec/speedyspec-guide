## Behaviour

PHP 8's `str_contains()`: whether a string contains another; an empty needle always is. WordPress defines it only when PHP doesn't have it. <Ev source="wp:wp-includes/compat.php#L499-L505" hash="3ab32ace46fa1036f88c2050a4bd9a7c4b59195810177faeaedbd7c39632ea7d"/>

## Override

Not overridable.
