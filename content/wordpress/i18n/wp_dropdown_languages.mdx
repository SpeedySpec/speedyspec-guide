## Behaviour

A `select` of the given languages, with English first (or the site default), named in their own language. It asks the translations API for names unless given them, and can list translations available to install. <Ev source="wp:wp-includes/l10n.php#L1895-L2021" hash="cb440d3fe5e4bbc41b659b08516fd6b694303b7400b2a0980e1166bfc31f5af8"/>

## Override

Not overridable.
