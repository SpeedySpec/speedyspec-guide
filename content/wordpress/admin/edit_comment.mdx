## Behaviour

Saves a comment from the comment edit form: author, email, URL, content, status and date; gives the result. The comment type can't be changed, and moving the comment to another post must pass `_wp_check_comment_target_post()`. <Ev source="wp:wp-admin/includes/comment.php#L56-L222" hash="4e62f3fdc05768f1485ae187505e41487302b900c94ca5f82841dd1df6f49d69"/>

## Override

Not overridable.
