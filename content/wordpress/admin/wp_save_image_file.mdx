## Behaviour

Saves an image editor's image to a file in its MIME type, through image_editor_save_pre and wp_save_image_editor_file; gives the result. <Ev source="wp:wp-admin/includes/image-edit.php#L435-L517" hash="42412daa52ff6dce032b6f353674fda2cae95b3aee258412464812ca7b152651"/>

## Override

`image_editor_save_pre`, `wp_save_image_editor_file`, `image_save_pre`, `wp_save_image_file`, `jpeg_quality` filter it.
