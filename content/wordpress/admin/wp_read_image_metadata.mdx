## Behaviour

The EXIF and IPTC data of an image file (camera, aperture, shutter speed, date taken, caption, copyright and the rest), or false; filtered by wp_read_image_metadata. <Ev source="wp:wp-admin/includes/image.php#L825-L1086" hash="9f917e241f88890ec987dcddc636fbe4cbe5faa2f4b89337622c10c0d97dce8d"/>
