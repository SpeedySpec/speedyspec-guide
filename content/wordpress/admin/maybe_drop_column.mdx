## Behaviour

Drops a table's column with an ALTER TABLE statement when it exists, and says whether it is gone; for old upgrade scripts. Defined in wp-admin/install-helper.php, which loads WordPress when included. <Ev source="wp:wp-admin/install-helper.php#L129-L152" hash="ce805377e73a1a1d6ebc034f4ce4170871ac1d73cd0a70a0c8906a266b3ad328"/>

## Override

Not overridable.
