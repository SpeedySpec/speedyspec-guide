## Behaviour

Emails a new user's details: to the admin, and to the user with a link to set their password; notify picks admin, user or both. <Ev source="wp:wp-includes/pluggable.php#L2283-L2435" hash="a200a0b71b708b804b4a51fe292c6c94e754a70d34845582d6d7e99564973775"/>

## Override

`wp_send_new_user_notification_to_admin`, `wp_new_user_notification_email_admin`, `wp_send_new_user_notification_to_user`, `wp_new_user_notification_email` filter it.
