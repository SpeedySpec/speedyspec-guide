## Behaviour

Emails a user that an application password was made for their account, with its name; send_application_password_created_notification can stop it. <Ev source="wp:wp-includes/functions.php#L9600-L9727" hash="3bd663ba7a45cad5d17547cd0881e55aee1dd61b4053885bb3b7fc78e0c88cb5"/>

## Override

`wp_send_application_password_created_email`, `wp_application_password_created_email` filter it.
