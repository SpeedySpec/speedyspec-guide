## Behaviour

The readonly attribute when two values match, deprecated in 5.9.0 for wp_readonly(). WordPress loads it only on PHP before 8.1, where readonly isn't yet a keyword, so on this PHP it doesn't exist. <Ev source="wp:wp-includes/php-compat/readonly.php#L34-L37" hash="7fed3cf8bbf830af28667d29e805bbffcfd4fd2a63cc341053444aff5770bc26"/>
