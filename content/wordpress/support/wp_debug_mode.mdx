## Behaviour

Sets error reporting from WP_DEBUG, WP_DEBUG_DISPLAY and WP_DEBUG_LOG: with debugging off only the serious errors are reported; enable_wp_debug_mode_checks can skip it. <Ev source="wp:wp-includes/load.php#L583-L653" hash="4f43f6fc2ab660db0d508afc49286d7e166a62517b4a2fb8265ee0d1034c079d"/>

## Override

`enable_wp_debug_mode_checks` filters it.
