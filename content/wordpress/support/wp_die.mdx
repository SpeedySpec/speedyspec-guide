## Behaviour

Ends the request with a message (or a WP_Error's messages), a title and a response code (500 by default), through the handler for the request type: AJAX, JSON, JSONP, XML-RPC, XML or the HTML page; the wp_die_*_handler filters pick it. ## Override

`wp_die_ajax_handler`, `wp_die_json_handler`, `wp_die_jsonp_handler`, `wp_die_xmlrpc_handler`, `wp_die_xml_handler`, `wp_die_handler` filter it.
