## Behaviour

A hash of a password for storing: bcrypt with a $wp prefix (the password pre-hashed with HMAC-SHA384); wp_hash_password_algorithm and _options can change it. <Ev source="wp:wp-includes/pluggable.php#L2790-L2854" hash="964514df8ec7fa193134f819759b3e41f2fadbb938c2a8306b4b2514826e72c8"/>

## Override

`wp_hash_password_algorithm`, `wp_hash_password_options` filter it.
