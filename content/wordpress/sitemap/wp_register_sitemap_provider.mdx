## Behaviour

Registers a sitemap provider by name; returns whether it was added (a name already taken is refused). <Ev source="wp:wp-includes/sitemaps.php#L67-L71" hash="ec3357d8214c79a6d24dff0e94f0c7e4b7a7ae4013b375639a891cb0496508cc"/>

## Override

`wp_sitemaps_add_provider` can replace or refuse the provider.
