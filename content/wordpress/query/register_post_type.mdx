## Behaviour

Registers a post type with its labels, visibility, capabilities, supports, taxonomies, rewrite and REST settings; fires registered_post_type; an error for invalid names. <Ev source="wp:wp-includes/post.php#L1859-L1913" hash="37da1be1405350c7c19b2a43d82c97982d4f63bf1f88e5a68b480d5a8891977d"/>

## Override

`registered_post_type`, `registered_post_type_{$post_type}` fire.
