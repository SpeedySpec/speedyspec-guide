## Behaviour

Whether a query is a random content request: the main front-end query of a GET or HEAD request for the home or an archive with the random variable, and a randomable post type to pick from; never singular, search, feed or sitemap requests. <Ev source="wp:wp-includes/query.php#L1308-L1324" hash="600e22b063a7941181d51b53607f084b4a2207d947fdcbbb4497f21dde717910"/>

## Override
