## Behaviour

Registers a script module by ID with its source, dependencies (static, or dynamic for lazy imports), version and arguments; enqueued, it prints as a module script, and its dependencies go in the import map. <Ev source="wp:wp-includes/script-modules.php#L71-L73" hash="0c41b2ffea1303f4cca86a495d95a8fbc1fa153b9d3835d6d03fb22ecad1181c"/>
