The `pingback.ping` method: registers a pingback from a source URL to a post on the site. It finds the target post, checks that pings are open and it isn't already registered, then fetches the source, which must have a title and a link to the target. Each failure is a pingback fault. It saves the pingback comment and fires `pingback_post`.
