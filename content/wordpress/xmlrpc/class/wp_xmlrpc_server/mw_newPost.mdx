The `metaWeblog.newPost` method: creates a post or page from the MetaWeblog struct (title, description, more text, excerpt, keywords, categories, dates, slug, password, author, comment and ping status, format, thumbnail, custom fields and enclosure). It fires `xmlrpc_call_success_mw_newPost`.
