Maps the method names to the server's methods (`wp.getCategories`, `wp.uploadFile` and `wp.deleteFile` are aliases). It sets up the options `wp.getOptions` describes, lets `xmlrpc_methods` change the methods, and decides whether XML-RPC is on. <Ev source="wp:wp-includes/class-wp-xmlrpc-server.php#L80-L190" hash="2283de5ec897159f8969a3342242c9b1fb17a6f5675a2cf0faf682082882d828"/>
