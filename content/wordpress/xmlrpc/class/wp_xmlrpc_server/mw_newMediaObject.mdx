The `metaWeblog.newMediaObject` method (and `wp.uploadFile`): uploads a file and creates its attachment, for a user who can upload files (and edit the post it is attached to). `pre_upload_error` can refuse it, and it fires `xmlrpc_call_success_mw_newMediaObject`. It logs the user in first, answering a 403 fault to wrong credentials. <Ev source="wp:wp-includes/class-wp-xmlrpc-server.php#L6621-L6738" hash="44f9ebb8d4b65ea8d285e08fb5559b11271b413eabb8b8ca90efb320fbbe143a"/>
