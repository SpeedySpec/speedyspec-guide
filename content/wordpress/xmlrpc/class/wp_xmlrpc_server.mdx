WordPress's XML-RPC server, behind `xmlrpc.php`: it extends `IXR_Server` with the WordPress (`wp.*`), Blogger, MetaWeblog, Movable Type and pingback APIs. Each method takes its arguments as one array, logs the user in where it acts for one, checks their capabilities, and fires `xmlrpc_call`. <Ev source="wp:wp-includes/class-wp-xmlrpc-server.php#L23-L7380" hash="57f983ce2a08fb343eb08dcfaf19e1ce046570080fd8ea09e63d877af8961003"/>
