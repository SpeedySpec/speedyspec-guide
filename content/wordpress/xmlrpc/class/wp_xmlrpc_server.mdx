WordPress's XML-RPC server, behind `xmlrpc.php`: it extends `IXR_Server` with the WordPress (`wp.*`), Blogger, MetaWeblog, Movable Type and pingback APIs. Each method takes its arguments as one array, logs the user in where it acts for one, checks their capabilities, and fires `xmlrpc_call`. <Ev source="wp:wp-includes/class-wp-xmlrpc-server.php#L23-L7431" hash="a2c20166dd177bd0bce4a55155b568c74b93218788563e4fe540dc36fe2797ba"/>
