## Behaviour

Adds or replaces a rewrite tag, a `%name%` that stands for a regex in structures and for a query var in the rule's query. Without a query, the query var is the tag's name and is made public. A name not wrapped in `%` is ignored. <Ev source="wp:wp-includes/rewrite.php#L162-L177" hash="eacbab2ab56ac3662b9ec2ee6d400dcc9ce42ee069dfbc2599abe527869991b7"/>

## Override

Not overridable.
