## Behaviour

Renders the [audio] shortcode: an audio element with the file's sources for MediaElement.js, or a link for others; wp_audio_shortcode_override can replace it. <Ev source="wp:wp-includes/media.php#L3534-L3709" hash="487e0317b6b5c1cbf747d4be24c4faa29af5a9b63bc029e9ee919112dee818e2"/>

## Override

`wp_audio_shortcode_override`, `wp_audio_shortcode_library`, `wp_audio_shortcode_class`, `wp_audio_shortcode` filter it.
