## Behaviour

Adds auto to the start of a lazy-loaded img tag's sizes attribute, when it has a width, so the browser picks the size; filtered by wp_img_tag_add_auto_sizes. <Ev source="wp:wp-includes/media.php#L2117-L2167" hash="6308b5fc8f18673d47647779befefc41b64f7e2121ba38cd7b067a24aedb2739"/>
