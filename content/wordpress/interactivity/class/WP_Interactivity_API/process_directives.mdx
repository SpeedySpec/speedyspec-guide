Processes directives in markup; see `wp_interactivity_process_directives()`. It saves and restores the stacks around the call, so it can be called while processing. Markup with unbalanced tags is returned unprocessed, and HTML from `data-wp-html` is put in only after processing. <Ev source="wp:wp-includes/interactivity-api/class-wp-interactivity-api.php#L517-L566" hash="36312947a60383de21e806fe50aa8cf90e69a20e3b422e96a3e035f45614ae17"/>
