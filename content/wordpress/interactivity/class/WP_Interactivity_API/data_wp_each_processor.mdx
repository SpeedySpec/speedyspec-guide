On a `template` with `data-wp-each`, renders the template's content once per item of the list it evaluates to. Each item is in the context as `item`, or the name after `--` in camelCase. Each copy is marked with `data-wp-each-child`. A value that isn't a list, content that isn't elements, or a list already rendered leaves the template as it is. <Ev source="wp:wp-includes/interactivity-api/class-wp-interactivity-api.php#L1949-L2040" hash="224dd30bb4df4935d64ffe4be37700653f77db5a424055dfa99a1620f8b01ac1"/>
