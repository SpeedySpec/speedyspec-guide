Replaces the element's content with the HTML of a `WP_Interactivity_Dangerous_HTML` token from the store. Any other value empties it and is reported. It does nothing with `data-wp-text`, `data-wp-each` or `data-wp-router-region` on the same element, which it reports. The HTML is held in a placeholder until processing ends, so its own directives aren't processed.
