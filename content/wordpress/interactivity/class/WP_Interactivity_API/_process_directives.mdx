Walks the markup's tags, calling each directive's processor on entering an element and, in reverse order, on leaving it. Directives inside `SVG` and `MATH` are reported and ignored, and elements already rendered by `data-wp-each` are skipped. It returns `null` when the tags don't balance. <Ev source="wp:wp-includes/interactivity-api/class-wp-interactivity-api.php#L582-L758" hash="f0756f7c14ef19bee9640e5055f4c8ea8474cbee3eed073535ece3ed16f241cd"/>
