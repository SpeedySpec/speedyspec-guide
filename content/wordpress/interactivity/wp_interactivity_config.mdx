## Behaviour

Merges configuration into a store namespace, recursively, and returns that namespace's configuration. It is sent to the browser with the state but isn't readable by directives. <Ev source="wp:wp-includes/interactivity-api/interactivity-api.php#L81-L83" hash="4fd379624e059f846a4d43624a58a507ae54a7b8bd100cd5f66d9d985a165d1f"/>
