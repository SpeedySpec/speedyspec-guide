## Behaviour

Returns the current element's context for a namespace, the current namespace by default, while directives are processed, for example from derived state. Outside directive processing it is reported through `_doing_it_wrong()` and gives an empty array. <Ev source="wp:wp-includes/interactivity-api/interactivity-api.php#L125-L127" hash="8ddc6681e7ddac21a7e595314d15ca15c3147ced54e7897d349b4167bf97d774"/>

## Override

Not overridable.
