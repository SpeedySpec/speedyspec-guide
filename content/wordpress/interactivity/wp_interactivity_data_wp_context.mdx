## Behaviour

Builds a `data-wp-context` attribute for markup: the context JSON-encoded with `<`, `>`, `'`, `"` and `&` escaped, so it is safe inside single quotes, prefixed with `namespace::` when one is given. An empty context is `{}`. <Ev source="wp:wp-includes/interactivity-api/interactivity-api.php#L104-L109" hash="137b2eea7bea54308e0069235bd968a15f26c39611c747d506d3c7ba1cbd93cc"/>

## Override

Not overridable.
