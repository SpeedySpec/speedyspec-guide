## Behaviour

Builds a `data-wp-context` attribute for markup: the context JSON-encoded with `<`, `>`, `'`, `"` and `&` escaped, so it is safe inside single quotes, prefixed with `namespace::` when one is given. An empty context is `{}`. <Ev source="wp:wp-includes/interactivity-api/interactivity-api.php#L104-L109" hash="28a8f4003dcfbfb11c5455acd8117752edd31220638907ad01fac72705fbb36a"/>

## Override

Not overridable.
