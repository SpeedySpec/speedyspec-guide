Writes a menu item's `li` (id `menu-item-ID`, its classes) and link: `href`, `target`, `rel` (plus `privacy-policy` for that page), `aria-current` for the current item, and a `title` only when it differs from the title. The title goes through `the_title`; `before`, `after`, `link_before` and `link_after` wrap the link and its text. <Ev source="wp:wp-includes/class-walker-nav-menu.php#L167-L332" hash="22a8c6600f417de2e1678ff9dd6e07d9e54c24ffc4a3b2527c14536de96309ef"/>
