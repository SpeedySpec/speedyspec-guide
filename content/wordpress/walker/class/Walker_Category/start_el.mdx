Writes a category's link to its archive, with its description as the title when `use_desc_for_title` is set, a feed link when `feed` or `feed_image` is, and its count when `show_count` is. A name `list_cats` empties is skipped. In the `list` style it is an `li` with `cat-item` classes, plus `current-cat`, `current-cat-parent` or `current-cat-ancestor` relative to `current_category`. <Ev source="wp:wp-includes/class-walker-category.php#L101-L255" hash="f787c512f16883c3feb8ed03528b17fa6b9a89c627d578e902d053c6a74a4771"/>
