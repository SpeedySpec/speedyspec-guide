Suspends previewing the setting's option, so its preview filters pass the stored value through while the option is sanitized or saved. Suspensions are counted per option, and each must be matched by `resume_option_preview()`. <Ev source="wp:wp-includes/class-wp-customize-setting.php#L469-L478" hash="b8df92cf55ddb98a0b50849536ea1e269498079355cb5f56a6d88f8dbb19596f"/>
