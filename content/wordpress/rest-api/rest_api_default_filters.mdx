## Behaviour

Hooked to rest_api_init: adds the filters serving needs (CORS headers, the Allow header, _fields, OPTIONS answers, the index's application passwords), and while serving a REST request turns deprecation notices into response headers. <Ev source="wp:wp-includes/rest-api.php#L240-L258" hash="d15ef5f0f9ec6ca4579c88f999b176296d4c5a573694b862ccbbda7ae69648de"/>
