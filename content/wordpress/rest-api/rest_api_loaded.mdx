## Behaviour

Hooked to parse_request: when the request has a rest_route query variable and isn't an admin screen (`WP_ADMIN`), serves it through the REST server and stops; otherwise does nothing. <Ev source="wp:wp-includes/rest-api.php#L456-L504" hash="f31517a9bd0f63bd0036bd9a9065cdd3419ba7ad7fac2a0f800ecba5540d78f7"/>

## Override

Not overridable.
