## Behaviour

Hooked to deprecated_argument_run while serving a REST request: with WP_DEBUG and headers not yet sent, reports the argument in an X-WP-DeprecatedParam header instead of a notice; otherwise does nothing. <Ev source="wp:wp-includes/rest-api.php#L775-L788" hash="81770fb4a40a6c67db4903dea904399db34603f6a90ddcda02604fe5eecab5c3"/>
