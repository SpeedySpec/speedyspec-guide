## Behaviour

On authenticate: a user by login and password; an empty field, an unknown login or a wrong password is a WP_Error. A user already found is passed on. <Ev source="wp:wp-includes/user.php#L153-L229" hash="c91a830b5bcf64b5b9184c58c40f054a54905059ae48c058e60dd53c516c44fc"/>
