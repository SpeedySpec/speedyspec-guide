## Behaviour

Sends a user the password reset email, by login or email; an empty or unknown one is a WP_Error. <Ev source="wp:wp-includes/user.php#L3293-L3532" hash="39b4004a518bfe4a20a6d7fed9ef3d513ad66138d315512de0ba1a3696e18224"/>

## Override

`lostpassword_user_data`, `lostpassword_errors`, `send_retrieve_password_email`, `retrieve_password_title`, `retrieve_password_message`, `retrieve_password_notification_email` filter it; `lostpassword_post` fires.
