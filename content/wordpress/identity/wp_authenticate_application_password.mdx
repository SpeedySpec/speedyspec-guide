## Behaviour

On authenticate for API requests: a user by an application password (which then can't be used to log in elsewhere); outside API requests, or when application passwords are unavailable, the user is passed on. <Ev source="wp:wp-includes/user.php#L372-L511" hash="42c3987f898cf2b049b466bb2ab440e902d8c764aede67eb11cc0cfcff1c47a8"/>

## Override

`application_password_is_api_request` filters it; `application_password_failed_authentication`, `wp_authenticate_application_password_errors`, `application_password_did_authenticate` fire.
