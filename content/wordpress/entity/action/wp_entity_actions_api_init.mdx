## Behaviour

Fired once, by `WP_Entity_Actions_Registry`, the first time actions are read after `init` has completed. Actions are registered and unregistered on it; WordPress registers its own at priority 0. New in WordPress 7.2 (trunk); WordPress 7.1.5 has no entity API. <Ev source="wp:wp-includes/class-wp-entity-actions-registry.php#L476-L514" hash="317481968f7c4ada72a4f86b7ad6bbf28a2f9e4254d4d0e0e0cb1377b87bf373"/>
