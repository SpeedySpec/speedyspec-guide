Checks each field's `type` against the type schema of `WP_REST_Entity_Fields_Controller` and reports, through `_doing_it_wrong()`, fields whose type DataViews doesn't provide; they are still registered, and render without a control. It builds the controller on every call. <Ev source="wp:wp-includes/class-wp-entity-fields-registry.php#L648-L674" hash="965eeafdef76d3928f516ff5ad1dc354d5f9503f6c6cac8ed46dc3a0d2a41387"/>
