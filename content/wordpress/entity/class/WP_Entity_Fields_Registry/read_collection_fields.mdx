Reads every `*/field.php` of a collection, in folder order, each field's `id` defaulting to its folder's name. Fields that aren't arrays, have a bad id, or repeat an earlier id are skipped and reported. It returns the fields and whether any was skipped. <Ev source="wp:wp-includes/class-wp-entity-fields-registry.php#L937-L1003" hash="73555d9573ec1385d02029b2cc1375a55c1f2bf439e8ee65af2b04fb8e27e357"/>
