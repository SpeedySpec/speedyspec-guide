Holds the actions registered for each entity, by kind and name, and the script modules that run them. It is a singleton, and fires `wp_entity_actions_api_init` the first time it is read after `init`. New in WordPress 7.2 (trunk); WordPress 7.1.5 has no entity API. <Ev source="wp:wp-includes/class-wp-entity-actions-registry.php#L40-L755" hash="a6ca328b8278e61c3014182120ce98870d6b3ef9ee36c083d4ddcef2af3f0fd6"/>
