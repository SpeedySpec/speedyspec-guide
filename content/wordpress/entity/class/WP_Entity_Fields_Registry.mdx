Holds the fields registered for each entity, by kind and name, and the script modules that render them. It is a singleton, and fires `wp_entity_fields_api_init` the first time it is read after `init`. New in WordPress 7.2 (trunk); WordPress 7.1.5 has no entity API. <Ev source="wp:wp-includes/class-wp-entity-fields-registry.php#L41-L1067" hash="9fb1df19d8add08e0f3c57b4990149637dcc7533990f218128a4ed4686d0136b"/>
