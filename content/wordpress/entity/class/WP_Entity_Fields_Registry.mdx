Holds the fields registered for each entity, by kind and name, and the script modules that render them. It is a singleton, and fires `wp_entity_fields_api_init` the first time it is read after `init`. New in WordPress 7.2 (trunk); WordPress 7.1.5 has no entity API. <Ev source="wp:wp-includes/class-wp-entity-fields-registry.php#L41-L1059" hash="02eddab1977261a9c057e51ea39fa4be0880be3ac09f076c7b4ec1b989b5083f"/>
