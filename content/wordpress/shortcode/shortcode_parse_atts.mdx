## Behaviour

Parses a shortcode's attribute text into an array. Named values in double quotes, single quotes or none are keyed by their lowercased name, and values without a name are keyed by number. Values are unescaped like `stripcslashes()`, except that a hex or octal escape for `<`, `>`, `"` or `'` becomes its HTML entity, and a value holding an unclosed HTML element becomes an empty string. Text with nothing to parse gives an empty array. <Ev source="wp:wp-includes/shortcodes.php#L626-L688" hash="9d5093c564bdb2113a390f65902e5a797defab30b4b44fab12f731f34d7c7c8c"/>
