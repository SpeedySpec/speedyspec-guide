## Behaviour

Registers a feature the theme supports (post-thumbnails, html5, custom-logo, align-wide and others), with arguments merged into defaults; must happen before wp_loaded for title-tag. Some features also add their hooks. <Ev source="wp:wp-includes/theme.php#L2717-L2967" hash="78a8aa6dbdde66372924e01d970ceaeb0650cb02b1d4b74c4d88b8e2bf48984c"/>

## Override

Not overridable.
