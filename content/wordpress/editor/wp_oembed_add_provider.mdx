## Behaviour

Adds an oEmbed provider: an endpoint for URLs matching a wildcard pattern, or a regex when `$regex` is true. Before `plugins_loaded` it is queued for `WP_oEmbed` to add when it is created. <Ev source="wp:wp-includes/embed.php#L147-L154" hash="2d382cad2e74ebfdccbf355c56231d942143efdea9e3a0cabe455fa9a4b245aa"/>

## Override

`oembed_providers` filters the providers.
