## Behaviour

Not one hook: `apply_filters( $hook_name, … )` and its variants run whichever filter they are given, so this page stands for "the hook passed in". What a particular filter passes is on that filter's page. See [`apply_filters()`](/wordpress/hooks/apply_filters/). <Ev scenario="apply_filters_single_callback"/>
