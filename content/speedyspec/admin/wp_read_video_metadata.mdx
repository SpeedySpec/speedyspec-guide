## Behaviour

Native. The function reads the file through the media reader port and builds WordPress's array, keys in WordPress's order, `created_timestamp` included, then runs the `wp_read_video_metadata` filter with its four arguments. It returns `false` for a missing file; a stream-wrapper path is copied to a temporary file first. <Ev source="ss:crates/speedyspec-wp-media-php/src/media.php#L174-L179" hash="f191f7130d6f23720207a552f8916e92b35410ac455cba6ebc89c8bd0b36a449"/> <Ev test="speedyspec-wp-media-php::php::video_metadata_from_php"/> <Ev test="speedyspec-wp-media-php::php::matroska_creation_time_from_the_file"/> <Ev test="speedyspec-wp-media-php::php::stream_wrapper_path_is_copied"/>

It is compared with WordPress 7.1.5 and its bundled getID3 over a corpus of video files, and matches except for the differences listed with their reasons. WordPress's own `metadata.php` tests pass against it. <Ev test="speedyspec-wp-media-corpus::corpus::corpus_matches_wordpress_except_listed_differences"/> <Ev test="speedyspec-wp-media-corpus::uploads::uploads_match_wordpress_except_listed_differences"/> <Ev test="speedyspec-wp-media-php::wordpress::wordpress_media_tests_pass"/> The function follows 7.1.5; trunk (7.2) drops a check whose removal changes no output. <Ev source="ss:compat/media/DIFFERENCES.md#L10-L13" hash="bd72910a475ff0c33cba945dff4da5fbbe84f7ac498c0638643f91f69de4b067"/>

## Differences

- **The library.** Bitrates, a Matroska track's default language (getID3 writes `"und"`) and a QuickTime file's compressor name differ. <Ev source="ss:compat/media/DIFFERENCES.md#L21-L37" hash="bac496c63cc14f7724e46dce96933ad6a21ba46289a3b32c3ddf301d2580e556"/>
- **Tags from every format** when a file has no ID3. <Ev source="ss:compat/media/DIFFERENCES.md#L15-L19" hash="07319193d8b7062fc5b329b2a4029cd0bbbaca5013998f1201f8e8aeb9726518"/>
- **More formats.** Files getID3 reads only partly or not at all get full metadata. <Ev source="ss:compat/media/DIFFERENCES.md#L42-L44" hash="c34296ea2653cced9cf9ba39b386c3ae591f64e2c80bfc7ed48d0bd475834a81"/> <Ev source="ss:compat/media/DIFFERENCES.md#L136-L147" hash="ac61d062371af315facd1a7a9af279f9bdaa3d693adf41ab0aeb00595063decb"/>
- **The filter's `$data`** is the getID3-shaped view, with the neutral description under `speedyspec`; other getID3 keys are absent. <Ev source="ss:crates/speedyspec-wp-media/src/getid3/mod.rs#L1-L2" hash="c7359a262c53a10a414245735a00dfe756b6f6b3d27727c1a311b3f11ac9d18d"/>
