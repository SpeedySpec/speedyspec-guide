## Behaviour

Native. Stores `null`, `false` and `0` as values; an object is copied in and copied out again; the expiry is accepted and ignored, as in WordPress's request cache. <Ev scenario="set_overwrites" area="object-cache"/> <Ev scenario="stores_null_false_zero" area="object-cache"/> <Ev scenario="object_cloned_on_set_and_get" area="object-cache"/> <Ev scenario="expire_ignored" area="object-cache"/> <Ev test="speedyspec-wp-object-cache-php::php::replayed_scenarios_match_wordpress"/>

## Override

The function dispatches a use case through the container; bind another handler under its key, or put a `WP_Object_Cache` subclass in `$wp_object_cache`. See the architecture page.
