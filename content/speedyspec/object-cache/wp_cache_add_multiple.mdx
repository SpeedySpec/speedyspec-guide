## Behaviour

Native. Adds each value as `wp_cache_add()` does and returns a result per key; each object is copied. <Ev scenario="multiple_ops" area="object-cache"/> <Ev scenario="object_refs_multiple" area="object-cache"/> <Ev test="speedyspec-wp-object-cache-php::php::replayed_scenarios_match_wordpress"/>

## Override

The function dispatches a use case through the container; bind another handler under its key, or put a `WP_Object_Cache` subclass in `$wp_object_cache`. See the architecture page.
