## Behaviour

Native. Returns a value per key, `false` for a miss; an invalid key raises WordPress's notice. <Ev scenario="multiple_ops" area="object-cache"/> <Ev scenario="get_multiple_with_invalid_key" area="object-cache"/> <Ev test="speedyspec-wp-object-cache-php::php::replayed_scenarios_match_wordpress"/>

## Override

The function dispatches a use case through the container; bind another handler under its key, or put a `WP_Object_Cache` subclass in `$wp_object_cache`. See the architecture page.
