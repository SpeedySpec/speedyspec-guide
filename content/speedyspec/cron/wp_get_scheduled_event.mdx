## Behaviour

Native. Returns the event as a `stdClass`, the next one when no timestamp is given, with `pre_get_scheduled_event`. Every recorded scenario replays as in WordPress, and WordPress's own cron tests pass. <Ev area="cron" scenario="scheduled_event_lookups"/> <Ev area="cron" scenario="pre_get_scheduled_event_answers"/> <Ev test="speedyspec-wp-cron-php::wordpress::wordpress_cron_tests_pass"/>

## Override

The `cron` option is read and written through the `CronStore` port. To keep events somewhere else, build `CronApi` with another store; see the architecture page.
