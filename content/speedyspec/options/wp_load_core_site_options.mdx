## Behaviour

Native: the `LoadCoreSiteOptions` command. It does nothing on a single site or while installing, and on multisite primes the core network options. <Ev test="speedyspec-wp-options-memory::network_options::load_core_site_options_only_on_multisite"/> No recorded scenario or WordPress test covers it.

The list is WordPress 7.2's nine names, without `can_compress_scripts`, which 7.1.5 also primed. <Ev source="wp:wp-includes/option.php#L805" hash="28730a6e7fe3723e953914761cd4079efb8d9225d7c42afc90363a475de70713"/> <Ev source="ss:crates/speedyspec-wp-options/src/network.rs#L16-L26" hash="a2e2ca7200ae843726ed02bdf6e5be312343e3702d0abe322e4523958ef4ec4b"/>

## Override

Network options live in `wp_sitemeta` behind the `SitemetaRepository` port on multisite, and in the options API on a single site. See the architecture page.
