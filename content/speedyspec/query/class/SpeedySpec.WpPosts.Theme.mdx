## Override

Bind an object implementing it at `SpeedySpec\WpPosts\Theme` in the container. The default binding is `PhpTheme`, which calls WordPress's own theme functions, until the seam behind it is ported. The use cases resolve the port on every call (`Resolved`, a Proxy), so a binding made for the request applies. A binding that fails, or an object that doesn't implement the interface, is an `Error` from the post function, and nothing falls back to the default. An exception the object throws stops the use case and reaches the caller as the same object; what WordPress wrote before it stays written. <Ev source="ss:crates/speedyspec-wp-posts-php/src/write_ports.rs#L61-L98" hash="7c49351cfee2f55a7a8acc00d7d2cfa4b4b46556e9a9d48b452e7c9bf6f6d319"/> <Ev source="ss:crates/speedyspec-wp-posts-php/src/write_ports.rs#L589-L605" hash="36841070b24c064218076a2141e4512374174a1c265c7a4ee1c0d6f32920c4d1"/>
