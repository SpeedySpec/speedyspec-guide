It resolves the null defaults in WordPress's order, `map_meta_cap`'s back-compat rule for `post` and `page`, `cap`, `query_var` (through the `TitleSanitizer` port) and `rewrite`. <Ev source="ss:crates/speedyspec-wp-posts/src/post_type.rs#L175-L181" hash="0ce9d9ce35bc63bff6b04994a9fd1de06b04d81eaf145715b720db5688038a2a"/>

WordPress 7.2 adds two properties. `randomable`, when not given, becomes `publicly_queryable && (bool) has_archive`, after the `publicly_queryable` default; a given value is kept as it is. `show_in_abilities` becomes `true` only when it is exactly `true`, so `1` or an array gives `false`. <Ev source="ss:crates/speedyspec-wp-posts/src/post_type.rs#L196-L213" hash="1b9b77638ca51f477e28cba3b60e236d2a1b9d1806d73b4a7e79f3d21844766c"/>

`rewrite` is resolved only when the `RewriteContext` port says `is_admin() || get_option( 'permalink_structure' )`. With neither, `rewrite => true` stays `true`; with one, it becomes an array with `slug`, `with_front`, `pages`, `feeds` (forced to `has_archive` when that is falsy) and `ep_mask` (`permalink_epmask`, else `EP_PERMALINK`). <Ev source="ss:crates/speedyspec-wp-posts-contracts/src/ports.rs#L266-L270" hash="ecf223d778c25e3eb9da969f249a26279780d67ee2b15bcdf9a0faa2f351c8a7"/>
