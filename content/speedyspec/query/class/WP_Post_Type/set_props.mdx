Served by WordPress's PHP, as the whole class is until phase 4. Its Rust rule is `resolve_post_type`, after the `register_post_type_args` and `register_{$post_type}_post_type_args` filters, which phase 4 runs first. It resolves the null defaults in WordPress's order, `map_meta_cap`'s back-compat rule for `post` and `page`, `cap`, `query_var` (through the `TitleSanitizer` port) and `rewrite`. <Ev source="ss:crates/speedyspec-wp-posts/src/post_type.rs#L168-L174" hash="0ce9d9ce35bc63bff6b04994a9fd1de06b04d81eaf145715b720db5688038a2a"/>

`rewrite` is resolved only when the `RewriteContext` port says `is_admin() || get_option( 'permalink_structure' )`.
