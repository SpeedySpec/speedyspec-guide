## Behaviour

The PHP twin of the `Scheduling` port, the cron calls the post writers make: `clear_scheduled_hook()`, `schedule_single_event()` and `next_scheduled()`, as `wp_clear_scheduled_hook()`, `wp_schedule_single_event()` and `wp_next_scheduled()` answer them. `_transition_post_status()` unschedules `publish_future_post`, `_future_post_hook()` schedules it, and `_publish_post_hook()` schedules `do_pings`. ## Override

Bind an object implementing it at `SpeedySpec\WpPosts\Scheduling` in the container. In the worker the default binding is `CronScheduling`, the Rust adapter over the cron area's scheduling core, which the runtime passes to `PostsArea::new`, so the post seam depends on the cron contracts only; the compat replay binds `PhpScheduling`, which calls the cron functions through PHP. <Ev source="ss:crates/speedyspec-php-runtime/src/scheduling.rs#L1-L7" hash="ee6c71937ec252c0bbf47c336ac741182a98512aeaef9f4a7cedd2fb60372ae4"/> <Ev test="speedyspec-php-runtime::database::post_writers_schedule_through_the_rust_cron_core"/> <Ev source="ss:crates/speedyspec-wp-posts-php/src/write_ports.rs#L812-L815" hash="c733cccd85b2095ca597f6a7d7f7ec983b4e41808a9d1e0eee6feac14e0c5e8c"/> The use cases resolve the port on every call (`Resolved`, a Proxy), so a binding made for the request applies. A binding that fails, or an object that doesn't implement the interface, is an `Error` from the post function, and nothing falls back to the default. An exception the object throws stops the use case and reaches the caller as the same object; what WordPress wrote before it stays written. <Ev source="ss:crates/speedyspec-wp-posts-php/src/write_ports.rs#L61-L98" hash="7c49351cfee2f55a7a8acc00d7d2cfa4b4b46556e9a9d48b452e7c9bf6f6d319"/> The replacement test binds an object that records its calls, and publishing a post unschedules `publish_future_post` and schedules `do_pings` through it. <Ev test="speedyspec-wp-posts-php::replacement::main"/> <Ev source="ss:crates/speedyspec-wp-posts-php/tests/replacement.rs#L146-L195" hash="b0c3ee6585ab2b7ea978e7f406a099a7a943debb198d09ba65ce45f1dda86dd7"/>
