## Override

Bind an object implementing it at `SpeedySpec\WpPosts\Taxonomy` in the container. The default binding calls WordPress's own functions (`PhpTaxonomy`); the use cases resolve the port on every call (`ResolvedTaxonomy`), so a binding made for the request applies, and a binding that fails is an `Error` from the post function with no fallback.
