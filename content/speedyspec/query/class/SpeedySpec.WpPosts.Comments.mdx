## Behaviour

The PHP twin of the `Comments` port: `default_comment_status()` (`get_default_comment_status()`, which `wp_insert_post()` asks for the comment and ping status of a post given none), and the comment trashing, untrashing, deleting and deferred counting the 5b writers will call. ## Override

Bind an object implementing it at `SpeedySpec\WpPosts\Comments` in the container. The default binding is `PhpComments`, which calls WordPress's own comment functions, until the seam behind it is ported. The use cases resolve the port on every call (`Resolved`, a Proxy), so a binding made for the request applies. A binding that fails, or an object that doesn't implement the interface, is an `Error` from the post function, and nothing falls back to the default.
