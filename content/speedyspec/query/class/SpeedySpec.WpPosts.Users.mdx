## Behaviour

The PHP twin of the `Users` port, the user functions the post functions call until the users seam is ported: `is_user_logged_in()`, `get_current_user_id()` and `current_user_can()`, given the capability, then its arguments as a list. The reads ask it for `wp_count_posts()`'s `readable` count; `wp_insert_post()` asks it for the default author and the `tax_input` and `pending`-slug capability checks. ## Override

Bind an object implementing it at `SpeedySpec\WpPosts\Users` in the container. The default binding is PhpUsers, which calls WordPress's own functions, until the seam behind it is ported. The use cases resolve the port on every call (`Resolved`, a Proxy), so a binding made for the request applies. A binding that fails, or an object that doesn't implement the interface, is an `Error` from the post function, and nothing falls back to the default.
