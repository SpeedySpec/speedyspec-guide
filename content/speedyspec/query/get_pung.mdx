## Behaviour

Native: `post.php`'s `get_pung()` is a line of PHP over `SpeedySpec\WpPosts\Native\get_pung`, which dispatches the `GetPung` message to the handler bound at `SpeedySpec\WpPosts\GetPungHandler`, so a handler PHP binds there takes the call. <Ev source="ss:crates/speedyspec-wp-posts-php/src/posts.php#L75-L78" hash="52da9740326deb469a3d5029c6fe8f22392a5a63d730a0d0949e7a10b8536bd1"/> <Ev source="ss:crates/speedyspec-wp-posts/src/read/pings.rs#L70-L72" hash="fd1f3fd711871c802f7aa317456cb15e9fb6c5a44a8c8078cd04518aad2113b3"/>

It reads the post and splits its `pinged` on whitespace, dropping empties, then runs the `get_pung` filter. False when there is no post. <Ev test="speedyspec-wp-posts-php::compat::main"/> <Ev test="speedyspec-wp-posts-php::errors::main"/> <Ev source="ss:crates/speedyspec-wp-posts-php/tests/errors.rs#L133-L153" hash="3cfd8fd6fbab12349a424049127e74cc1b6207fead79ff16158f7548807b49a3"/>
