## Behaviour

Native: `post.php`'s `wp_get_post_parent_id()` is a line of PHP over `SpeedySpec\WpPosts\Native\wp_get_post_parent_id`, which dispatches the `WpGetPostParentId` message to the handler bound at `SpeedySpec\WpPosts\WpGetPostParentIdHandler`, so a handler PHP binds there takes the call. <Ev source="ss:crates/speedyspec-wp-posts-php/src/posts.php#L160-L163" hash="d1fa52abba47f36a076a6a19a0d2ec2e1f359ccec762c57d362a4ed2ff1e7c88"/> <Ev source="ss:crates/speedyspec-wp-posts/src/read/get.rs#L456-L458" hash="868ce188947ed44b2e324ec0c3bb3bc6eacf14c196ad31b6ca5e2994f325f65f"/>

It reads the post with `get_post()`, the global `$post` for an empty argument, and answers `(int)` `post_parent`: false when there is no post, the int 0 when it has no parent. <Ev scenario="parent-each" area="posts-read"/> <Ev scenario="parent-missing" area="posts-read"/> <Ev scenario="parent-global" area="posts-read"/> <Ev scenario="parent-object" area="posts-read"/> <Ev test="speedyspec-wp-posts-php::compat::main"/>

WordPress's own `Tests_Post_wpGetPostParentId` tests, copied from 7.2-RC2, call it and pass against the port on a single site and on multisite. <Ev test="speedyspec-wp-posts-php::wordpress::wordpress_posts_runs_pass"/>

## Differences

- **An object argument is read as a copy.** The readers beside `get_post()` hand an object argument to the use case as a copy, for one dispatch. WordPress's `get_post()` inside them sanitizes a `stdClass` with no `filter` in place, setting `filter` to `raw` and casting its ids to int; on SpeedySpec the caller's object is left as it was. The answer is the same. Not recorded. <Ev source="ss:crates/speedyspec-wp-posts-php/src/read.rs#L30-L34" hash="2bc082f37a3aa63398531ebb37534e185fe71501b2fbacd16834877684966948"/>

## The Rust rule

`post_parent_id` reads the post through the `PostReader` port and answers its `post_parent` (0 for none), or `None` (false) for a missing post. <Ev source="ss:crates/speedyspec-wp-posts/src/hierarchy.rs#L18-L21" hash="3dc1eff6ef1dbb8991030ae0d83451df92eb232bfc5f372eefa95c1c90ad960e"/>
