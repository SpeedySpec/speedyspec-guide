## The Rust rule

`is_post_status_viewable` is false when the status is `internal` or `protected`, else `publicly_queryable || ( _builtin && public )`, by PHP truth. `post_status_name_viewable` looks a string name up first and is false for a missing status. <Ev source="ss:crates/speedyspec-wp-posts/src/queries.rs#L41-L48" hash="289628fe79896613e721520e909ff031760fad81089d1964bc54795fa946e43d"/> <Ev source="ss:crates/speedyspec-wp-posts/src/queries.rs#L57-L62" hash="ebb37e7d127a2ebeb6de8159365f220ab738eb25db6a23d57ddb653431ecb115"/>

The 5 recorded calls in the `lists` scenario and 24 after `create_initial_post_types()` replay as in WordPress 7.2-RC2. <Ev test="speedyspec-wp-posts::recorded::list_scenarios_match_wordpress"/> <Ev test="speedyspec-wp-posts::recorded::initial_post_types_match_wordpress"/>

## Limits
