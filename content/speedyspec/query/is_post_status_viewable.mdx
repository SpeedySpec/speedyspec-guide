## The Rust rule

`is_post_status_viewable` is false when the status is `internal` or `protected`, else `publicly_queryable || ( _builtin && public )`, by PHP truth. `post_status_name_viewable` looks a string name up first and is false for a missing status. <Ev source="ss:crates/speedyspec-wp-posts/src/queries.rs#L48-L55" hash="289628fe79896613e721520e909ff031760fad81089d1964bc54795fa946e43d"/> <Ev source="ss:crates/speedyspec-wp-posts/src/queries.rs#L64-L69" hash="ebb37e7d127a2ebeb6de8159365f220ab738eb25db6a23d57ddb653431ecb115"/>
