## The Rust rules

`post_stati` (objects) and `post_status_names` (names) filter the `PostStatuses` port's list with the same `filter_object_list` as `get_post_types()`. An argument matches when the object has the property (`isset()`) and it is loosely equal, by PHP 8's `==`, to the wanted value: `'public' => 1`, `'1'` and `'yes'` all match `public => true`, and a null property never matches. Empty arguments return every entry whatever the operator; an unknown operator returns none. <Ev source="ss:crates/speedyspec-wp-posts/src/list.rs#L166-L185" hash="1cb39adcc2fba3db80e9af476758a3d26bef5ab45d6560fb748ea745eaaed86b"/>
