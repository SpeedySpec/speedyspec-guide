## The Rust rules

`post_types` (objects) and `post_type_names` (names) filter the `PostTypes` port's list with `filter_object_list`, which is `wp_filter_object_list()` over `WP_List_Util::filter()`. An argument matches when the object has the property (`isset()`) and it is loosely equal, by PHP 8's `==`, to the wanted value: `'public' => 1`, `'1'` and `'yes'` all match `public => true`, and a null property never matches. Empty arguments return every entry whatever the operator; an unknown operator returns none. Each entry keeps PHP's array key, so `"123"` comes back as the int key `123`; `names` plucks each object's `name` property. <Ev source="ss:crates/speedyspec-wp-posts/src/list.rs#L1-L11" hash="a8043967dee9aed4185800fcbb50c8aed36527d18642411aca550fc252bc0cbf"/> <Ev source="ss:crates/speedyspec-wp-posts/src/list.rs#L114-L121" hash="901c811955f72ed15726eddbc8090a5d2f0892b5373a6a656ec45428806c194c"/> <Ev source="ss:crates/speedyspec-wp-posts/src/list.rs#L140-L159" hash="7664f9a3f730bb710ce1c9a95001debec2dc0be383f25107925ddd42f476330e"/>
