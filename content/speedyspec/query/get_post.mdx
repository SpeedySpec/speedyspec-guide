## Behaviour

Native: `post.php`'s `get_post()` is a line of PHP over `SpeedySpec\WpPosts\Native\get_post`, which dispatches the `GetPostObject` message to the handler bound at `SpeedySpec\WpPosts\GetPostObjectHandler`, so a handler PHP binds there takes the call. <Ev source="ss:crates/speedyspec-wp-posts-php/src/posts.php#L25-L28" hash="0bd128e75cc399f6e1c08d3944948d36f7cbb43d7e2bcf4293923041d22665a6"/> <Ev source="ss:crates/speedyspec-wp-posts/src/read/get.rs#L258-L260" hash="63e67974ea2a1ea62fb077d86ddf78864370de2f27394af9fa88346d22d19b86"/> <Ev source="ss:crates/speedyspec-wp-posts-php/src/read.rs#L384-L454" hash="a2ddd6f3531d0c394423bbf5e7898539e7f614573857ae080e911ec6aa62a1f4"/> <Ev source="ss:crates/speedyspec-wp-posts-php/src/read.rs#L349-L353" hash="3702bd065b749f0b418d92a5187699971e9b67f38aecefb73a707a440e742d76"/> <Ev source="ss:crates/speedyspec-wp-posts-php/src/release.rs#L112-L122" hash="e1c170628b0080fe096ab946b279346880e1b64a87fb4ba133ff3e32a4d234c7"/>

It reads the post as `WP_Post::get_instance()` does: the `posts` cache entry first (a `stdClass` or `WP_Post` with an `ID`; anything else is a miss and is replaced), else one `SELECT * … WHERE ID = %d LIMIT 1`, whose row is cached with `wp_cache_set()`. An empty `$post` (nothing, `null`, `0`) is the global `$post`; a numeric one is an id through `(int)`, and nothing below 1 is read. A `WP_Post` it is given, or the global, is the object it works on, so `get_post( 0, OBJECT, 'display' )` sanitizes the global in place, as WordPress does through `WP_Post::filter()`, which stays WordPress's method. A post read by id is a new `WP_Post` each call. `ARRAY_A` and `ARRAY_N` are `to_array()` as in WordPress. `WP_Post::get_instance()` reads the same way: the prepared release keeps its signature and int checks and swaps its body for the native raw read (`post_instance()`), so a direct caller and `WP_Post::filter( 'raw' )` go through the bound post repository and the `posts` cache too, one read path for both. <Ev scenario="get-by-id" area="posts-read"/> <Ev scenario="get-by-numeric-string" area="posts-read"/> <Ev scenario="get-by-float" area="posts-read"/> <Ev scenario="get-by-object" area="posts-read"/> <Ev scenario="get-by-stdclass-raw" area="posts-read"/> <Ev scenario="get-by-stdclass-display" area="posts-read"/> <Ev scenario="get-array-a" area="posts-read"/> <Ev scenario="get-array-n" area="posts-read"/> <Ev scenario="get-filter-display" area="posts-read"/> <Ev scenario="get-filter-back-to-raw" area="posts-read"/> <Ev scenario="get-negative" area="posts-read"/> <Ev scenario="get-non-numeric" area="posts-read"/> <Ev scenario="get-global-zero" area="posts-read"/> <Ev scenario="get-global-display" area="posts-read"/> <Ev scenario="cache-non-object-entry" area="posts-read"/> <Ev scenario="cache-php-entry" area="posts-read"/> <Ev scenario="ms-get-switch" area="posts-read"/> <Ev test="speedyspec-wp-posts-php::compat::main"/> <Ev test="speedyspec-wp-posts-tests::read::get_post_zero_reads_current_post"/> <Ev test="speedyspec-wp-posts-tests::read::reads_php_shaped_post_entry"/> <Ev test="speedyspec-wp-posts-tests::read::non_object_entry_is_a_miss"/> <Ev test="speedyspec-wp-posts-tests::read::get_post_caches_on_miss_once"/> <Ev test="speedyspec-wp-posts-tests::read::warm_read_lends_the_cached_entry"/>
