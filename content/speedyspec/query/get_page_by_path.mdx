It follows WordPress step by step: the salted `post-queries` entry `get_page_by_path:` + `md5( $page_path . serialize( $post_type ) )` (a cached `0` is a known miss); the path `rawurlencode( urldecode() )`d with `%2F` and `%20` put back, trimmed and split on `/`, each part through `sanitize_title_for_query()`; one statement for the pages with those names (WordPress's text, with its `ORDER BY` on status); then the walk that matches each row's parents to the path, by `===`, so case counts there and the `sanitize_title` filter decides what matches. A string `$post_type` also searches attachments and keeps looking past one; an array stops at the first match.
