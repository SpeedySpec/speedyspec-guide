## Behaviour

Served by WordPress's PHP; the Rust rules below are not wired yet. The runtime worker links neither posts crate, so PHP on SpeedySpec runs WordPress's own `post.php` until phase 4 of the posts and meta port. <Ev source="ss:crates/speedyspec-php-runtime/Cargo.toml#L24-L60" hash="4e45d1d171d753b4dfe1c47e78d7b37982c3572c9fc8cf407854fed9c53b58e9"/>

## The Rust rules

`PostStatusRegistry::register` runs `sanitize_key()` with no length check, so `register_post_status( '' )` stores `''`, then stores the object in its old place when the name is already registered, else at the end. `resolve_post_status` is the object: `array_merge()` over WordPress's defaults, `name` set, then the null defaults resolved in WordPress's order (`internal` when none of `public`, `internal`, `protected` and `private` is given, then `publicly_queryable`, `exclude_from_search`, the two admin list flags, `date_floating`, `label` and `label_count`). <Ev source="ss:crates/speedyspec-wp-posts/src/status.rs#L66-L71" hash="8a92681c16fa8f4d7c9f3a8700a75d885cabd732cbc01fe61d1a4992aeee9737"/> <Ev source="ss:crates/speedyspec-wp-posts/src/status.rs#L128-L134" hash="b1da3b27ba9637746b73f39ead4336934e8e55432dea4eeba85b24efd9a31441"/>

The 14 recorded status scenarios (19 calls) replay as in WordPress 7.2-RC2, and so do the 4 calls in the `lists` scenario, comparing each result and `$wp_post_statuses` in order. <Ev test="speedyspec-wp-posts::recorded::status_scenarios_match_wordpress"/> <Ev test="speedyspec-wp-posts::recorded::list_scenarios_match_wordpress"/>

## Limits

- Recorded from WordPress 7.2-RC2 under the recorder's stubs: `__()` and `_x()` return their text, the rewrite functions do nothing, `register_taxonomy_for_object_type()` only notes its call, and `get_object_taxonomies()` returns nothing. <Ev source="ss:compat/posts/record.php#L53-L66" hash="6398e7220fdfb100a72b707de8a1729a005479e3dd92f38f53c6da72f86a0d8d"/> `_n_noop()` is copied from `l10n.php`.
- `$args` must be an array. The query-string form `wp_parse_args()` accepts is the adapter's to parse. <Ev source="ss:crates/speedyspec-wp-posts/src/status.rs#L5-L6" hash="7d3288d67d1538167e8f2036d43941adaadbfa7c53231454454a269722ceb084"/>
