## The Rust rule

`PostTypeRegistry::all_supports` gives a type's features in insertion order, each `true` or its arguments list; a missing type gives none. <Ev source="ss:crates/speedyspec-wp-posts/src/registry.rs#L331-L332" hash="26008f26ae3fd3bf73fd03b1682da0f15c3c74f628577587591d435a3755737b"/>

Its 3 recorded calls replay as in WordPress 7.1.5. <Ev test="speedyspec-wp-posts::recorded::post_type_scenarios_match_wordpress"/>
