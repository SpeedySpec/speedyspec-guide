## Behaviour

Native: `post.php`'s `wp_update_post()` is a line of PHP over `SpeedySpec\WpPosts\Native\wp_update_post`, which dispatches the `WpUpdatePost` message to the handler bound at `SpeedySpec\WpPosts\WpUpdatePostHandler`, so a handler PHP binds there takes the call. <Ev source="ss:crates/speedyspec-wp-posts-php/src/post-writes.php#L20-L23" hash="534e8eaf0f8aae2b13155e093ecd1b03902cf1eabcaa68561ce8a43fe6f3be1a"/> <Ev source="ss:crates/speedyspec-wp-posts-php/src/write.rs#L140-L151" hash="22d1136dc9fb889333a0ad8c0958f94e4662832cb1d9362d09f26a1a368ea9d9"/> <Ev source="ss:crates/speedyspec-wp-posts/src/write/messages.rs#L38-L39" hash="52cdeb810ef46f31d22266860858b5434c4ad8de5dacf79572970a1b94439acf"/>

It follows WordPress step by step: an object is read with `get_object_vars()` and slashed; the post is `get_post( $postarr['ID'], ARRAY_A )` (the global `$post` for an empty id), with `WP_Post::to_array()`'s `ancestors`, `page_template`, `post_category` and `tags_input`, and none is `invalid_post`; the stored fields, slashed, go under the given ones; the given categories win when there are some; a draft with no GMT date and no `edit_date` takes the current time as its date; an attachment goes to `wp_insert_attachment()` through the Uploads port; `tags_input` equal to the post's tag names is dropped; then the native [wp_insert_post()](/speedyspec/query/wp_insert_post/). <Ev source="ss:crates/speedyspec-wp-posts/src/write/update.rs#L19-L67" hash="c38ebb75efc2588e26c62085dfa14c1ed34878848f2f8e84749d6d42b873e51d"/>

A `$postarr` that is neither an array nor an object fails as PHP fails, before anything is written: a string throws `TypeError` at `$postarr['ID']`; any other scalar or `null` reads the global `$post` and then throws `array_merge()`'s `TypeError`, or answers `invalid_post` with no global post. <Ev test="speedyspec-wp-posts-tests::write::scalar_postarr_to_wp_update_post_throws"/>

**Verified against WordPress 7.2-RC2** by the `compat/posts-write` replay, single site and multisite: partial updates, status changes, the draft date rule, `post_updated`'s arguments, a missing post, kept categories, and the loop breaking `wp_check_post_hierarchy_for_loops()` does through it. <Ev scenario="update-partial" area="posts-write"/> <Ev scenario="update-status" area="posts-write"/> <Ev scenario="update-date-clear-draft" area="posts-write"/> <Ev scenario="update-date-edit-date" area="posts-write"/> <Ev scenario="update-post-updated-arguments" area="posts-write"/> <Ev scenario="update-missing" area="posts-write"/> <Ev scenario="update-categories-keep" area="posts-write"/> <Ev scenario="insert-parent-loop-self" area="posts-write"/> <Ev scenario="insert-parent-loop-broken" area="posts-write"/> <Ev scenario="auto-drafts-insert" area="posts-write"/> <Ev scenario="ms-switch-insert" area="posts-write"/> <Ev test="speedyspec-wp-posts-php::compat_write::main"/> <Ev test="speedyspec-wp-posts-tests::write::updates_replay"/> <Ev test="speedyspec-wp-posts-tests::write::loop_is_broken_through_wp_update_post"/> <Ev test="speedyspec-wp-posts-tests::write::update_keeps_a_column_the_filter_dropped"/>

An exception from `save_post` after an update leaves the row changed, as in WordPress, and reaches the caller as the same object. <Ev source="ss:crates/speedyspec-wp-posts-php/tests/errors.rs#L297-L310" hash="f17bce463b5d504a59038919c97325e6d5314002a0b15f89a683eea346d10d41"/> <Ev test="speedyspec-wp-posts-php::errors::main"/>

WordPress's own `Tests_Post_wpInsertPost`, `Tests_Post_wpAfterInsertPost`, `Tests_Post_Slashes`, `Tests_Post`, `Tests_Post_wpPublishPost` and `Tests_Taxonomy_UpdateTermCountOnTransitionPostStatus` tests, copied from 7.2-RC2, call it and pass against the port on a single site and on multisite. <Ev test="speedyspec-wp-posts-php::wordpress::wordpress_posts_runs_pass"/>

## Differences

- **An update's non-array `$data`.** See [wp_insert_post()](/speedyspec/query/wp_insert_post/): `$wpdb->update` sends no statement, and the `db_update_error`'s data is an empty string rather than the stale `$wpdb->last_error`. <Ev source="ss:crates/speedyspec-wp-posts/src/write/insert.rs#L722-L741" hash="497be166f706829e74cf94bd7fe784aa64d7327e5ad1dcbbed6f96611217c64f"/>
- **A non-integer parent from the filter** is cast with `(int)` before the slug filters and `wp_insert_post_data` see it. <Ev source="ss:crates/speedyspec-wp-posts/src/write/insert.rs#L590-L609" hash="77199ad6bb666ef5d8d7ec77a7b5c849419aae6f89b33a32a87a495fbb9cbe83"/>
