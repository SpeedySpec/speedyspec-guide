  - summary: "A query-string `$postarr` with bracketed names (`tags_input[]=a`) is read as flat names, where PHP's `parse_str()` builds nested arrays, and PHP's name mangling (spaces and dots to `_`) is not applied."
  - summary: "`wp_unique_post_slug()` reads `get_option( 'permalink_structure' )` on every slug check, where WordPress reads it only for a numeric flat slug, so an `option_permalink_structure` callback runs more often. The option is autoloaded, so it is read from the options cache and no statement is added."

## Behaviour

Native: `post.php`'s `wp_insert_post()` is a line of PHP over `SpeedySpec\WpPosts\Native\wp_insert_post`, which dispatches the `WpInsertPost` message to the handler bound at `SpeedySpec\WpPosts\WpInsertPostHandler`, so a handler PHP binds there takes the call. <Ev source="ss:crates/speedyspec-wp-posts-php/src/post-writes.php#L15-L18" hash="325cb39441445b16af39c36bf64bf848c28b4d7c3b749349c36a477cac4df211"/> <Ev source="ss:crates/speedyspec-wp-posts-php/src/write.rs#L131-L138" hash="c2eff2246e7cb9d169958bbdcb1df8c62b1759de82ada922d569d19235e83d2f"/> <Ev source="ss:crates/speedyspec-wp-posts/src/write/messages.rs#L36-L37" hash="121ca3df035f288ceddd5debe376c57f047f182550343ee8a5b0d5eb17d37308"/> <Ev source="ss:crates/speedyspec-wp-posts-php/src/release.rs#L76-L83" hash="ceaea9403882ed6e7b9fcb83d5e9b5e209866a4de37af848a8f17afc933d0747"/>

The use case is a Composed Method: `Insert::run` calls nine private steps in WordPress's order, each a pure function or a call through a port. No step is overridden. To change it, bind a port or bind another handler. <Ev source="ss:crates/speedyspec-wp-posts/src/write/insert.rs#L1-L23" hash="f3b8467c868478a356e930dc2bfc54ddf78091d746f048932284479f32998a22"/> <Ev source="ss:crates/speedyspec-wp-posts/src/write/insert.rs#L255-L272" hash="8fd1a5bafe3ec808d81968eb7f4cd20acc980737400d0532cd55e7c840a839c3"/>

1. **Parse:** the defaults (`post_author` is the current user, through the Users port), `wp_parse_args()` with its `wp_parse_str` filter, `sanitize_post( 'db' )`, and, with an `ID`, the post before the update.
2. **Empty content:** the `wp_insert_post_empty_content` filter; a truthy answer is `empty_content`.
3. **Resolve:** status, categories, the `pending` slug rule, `sanitize_title()`, `wp_resolve_post_date()` and the dates, comment and ping status (`get_default_comment_status()` through the Comments port), password, menu order and parent.
4. **Parent:** the `wp_insert_post_parent` filter. Its default callback, the native [wp_check_post_hierarchy_for_loops()](/speedyspec/query/wp_check_post_hierarchy_for_loops/), runs inside it and breaks a loop through `wp_update_post()` before any slug is chosen.
5. **Slug:** a restored post takes back its `_wp_desired_post_slug`, a trashed post holding the wanted slug gives it up (`add_trashed_suffix_to_trashed_posts`), a post being trashed takes the `__trashed` suffix, then `wp_unique_post_slug()`'s rules with their filters.
6. **Data:** `$data` in `compact()`'s order, emoji encoded in the title, content and excerpt when their column is `utf8` or `utf8mb3` (the Charset port), the `wp_insert_post_data` filter (or `wp_insert_attachment_data`), then `wp_unslash()`.
7. **Write:** `pre_post_update` and the repository's update, or the `import_id` check, `pre_post_insert` and the insert, each of exactly the filtered `$data` (`PostRow`), so a column a callback dropped is not written and a key it added is.
8. **After the write:** the slug of a published post written without one, the categories, tags, default terms and `tax_input` (the Taxonomy port), `meta_input`, the GUID of a new post (the Rewrite port), an attachment's file and context, the featured image (the Uploads port), and `clean_post_cache()`.
9. **Finish:** `get_post()`, the page template (the Theme port), `wp_transition_post_status()`, `edit_post`, `post_updated`, `save_post_{$post_type}`, `save_post`, `wp_insert_post` and, unless `$fire_after_hooks` is false, `wp_after_insert_post`. These hooks share one `WP_Post`, built once, so a callback's change to it is what the next hook reads. The `$post_after` that `post_updated` and `attachment_updated` receive is the exception: it is a fresh `get_post()`.

## Differences

- **A non-integer parent from the filter.** The `wp_insert_post_parent` answer is kept as an integer, or `null`: anything else is cast with `(int)`. WordPress hands the raw value on to `wp_unique_post_slug()`, its `pre_wp_unique_post_slug` and `wp_unique_post_slug_is_bad_hierarchical_slug` filters, and `wp_insert_post_data` (`'7'`, not `7`). The statements are the same either way, since `%d` prints the same integer. <Ev source="ss:crates/speedyspec-wp-posts/src/write/insert.rs#L590-L609" hash="77199ad6bb666ef5d8d7ec77a7b5c849419aae6f89b33a32a87a495fbb9cbe83"/> <Ev source="ss:crates/speedyspec-wp-posts-contracts/src/values.rs#L98-L104" hash="20aae44f55c5b0d8215110a3598fe745984aa4fe4ed383411ee280a85c4cc4bf"/>
- **An update's non-array `$data`.** When a `wp_insert_post_data` callback answers something other than an array on an update, `$wpdb->update` sends nothing and WordPress's `db_update_error` carries whatever `$wpdb->last_error` an earlier statement left. The repository port can't read that, so the data is an empty string. It is diagnostic data only; the code and message are WordPress's. <Ev source="ss:crates/speedyspec-wp-posts/src/write/insert.rs#L722-L741" hash="497be166f706829e74cf94bd7fe784aa64d7327e5ad1dcbbed6f96611217c64f"/>
- **Query-string `$postarr`.** `wp_parse_args()` of a string reads flat names only: `a[]=1` and `a[b]=1` stay flat, and spaces and dots in names are not turned into `_`. <Ev source="ss:crates/speedyspec-wp-posts/src/write/php.rs#L74-L79" hash="cd2157fa5b85928d26d3f70d9658fd0bea0d130e41bf79d1f6094429a6ea4d0c"/>
- **`permalink_structure` read eagerly.** The slug settings port reads `$wp_rewrite`'s feeds and pagination base and `get_option( 'permalink_structure' )` together, on every slug check. <Ev source="ss:crates/speedyspec-wp-posts-php/src/write_ports.rs#L742-L775" hash="5087d38c586f630fbefc5af2d72857bb6858540af9783296a9a342374d65986a"/>
