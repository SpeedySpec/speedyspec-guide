## Behaviour

Served by WordPress's PHP; the Rust rules below are not wired yet. The runtime worker links no posts crate, so PHP on SpeedySpec runs WordPress's own `post.php` until phase 4 of the posts and meta port. <Ev source="ss:crates/speedyspec-php-runtime/Cargo.toml#L20-L55" hash="955f1ccec24cc11da3fa0826db96868561c6e6c3cdc55277b37b80c09b513508"/>

## The Rust rule

`page_uri` is `get_page_uri()` before its `get_page_uri` filter, for a page already read: each ancestor's name, then `/`, nearest last, before the page's own name. An ancestor named `""` or `"0"` is false in PHP and left out. As in WordPress, `$page->ancestors` reads every ancestor, then each one is read again for its name. <Ev source="ss:crates/speedyspec-wp-posts/src/hierarchy.rs#L157-L171" hash="9580e160ea1319a8723ac2909f28debb657df6f121321ba350f8604abfa13701"/>

The 4 recorded calls replay as in WordPress 7.2-RC2, comparing the URI and every post read, in order: a deep page under an ancestor with an empty name, with a percent-encoded name of its own, a middle page, a top-level page and a missing page (false). <Ev test="speedyspec-wp-posts::entity::hierarchy_matches_wordpress"/> <Ev source="ss:compat/posts-entity/record.php#L634-L671" hash="6f47b85147282bdf090f33ec9af0e325f028a7ac61bc8eb02647a03f03402cde"/>

## Limits

- The `get_page_uri` filter is phase 4's.
- The rule takes the page; the adapter reads the argument with `get_post()` and answers false when there is none.
- `Uncached` reads every post through `find`, as WordPress does with no object cache; phase 4's reader reads the `posts` cache group first. <Ev source="ss:crates/speedyspec-wp-posts/src/reader.rs#L5-L19" hash="09da15425c05c61578f330c352c0763b5ac7394e30c22dffec7fbfac1012ace4"/>
- Recorded from WordPress 7.2-RC2 behind the recorder's stub `$wpdb`, which answers only the statements `PostRepository` mirrors and compares strings byte for byte. MySQL's `_ci` collations ignore case and trailing spaces, so rows that differ only so are not proven; the SQL repository (phase 4) decides. <Ev source="ss:compat/posts-entity/record.php#L133-L137" hash="582625381c482b18c1cd564398a320d093d272f1212981bd5dec09dfd0828f01"/>
