## Behaviour

SpeedySpec doesn't declare the class: `class_exists( 'WP_Filter_Sentinel' )` is false on the runtime. <Ev example="hooks/class--WP_Filter_Sentinel/not-declared-on-speedyspec"/>

## Porting

Use a fresh `stdClass` where the class doesn't exist: any new object is unique by identity, which is all a sentinel needs. The porting example below runs on both. <Ev example="hooks/class--WP_Filter_Sentinel/porting-after"/> It is listed in [the guide's findings](https://github.com/SpeedySpec/speedyspec-guide/blob/main/docs/hooks-findings.md) for speedyspec-server.
