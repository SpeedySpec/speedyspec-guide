## Behaviour

Installs the proxies as `$wp_filter`, `$wp_filters`, `$wp_actions` and `$wp_current_filter` at the start of every request, so WordPress code that reaches for the globals finds them. <Ev test="speedyspec-wp-hooks-php::php::wp_filter_reads_and_iterates_like_wordpress"/> Not for plugins.
