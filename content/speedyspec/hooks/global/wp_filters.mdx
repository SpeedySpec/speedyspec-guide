## Behaviour

`$wp_filters` is a proxy object (`SpeedySpec\WpHooks\CountGlobal`) over the store's counts. Reading a count and setting one behave as in WordPress. <Ev scenario="wp_filters_read_and_write"/>

## Limits

An object, not an array: array functions throw a `TypeError`. Read counts with `did_filter()`. <Ev source="ss:compat/hooks/breaks.json#L31-L36" hash="54b93d5ce67537aac4a63b115152329265e083c37e3e600e441dc4f2b8368703"/>

## Porting

To count from a point, subtract an earlier `did_filter()` instead of resetting `$wp_filters`. <Ev break="wp_filters_read_and_write"/>
