## Behaviour

A proxy object (`SpeedySpec\WpHooks\CountGlobal`) over the store's action counts; reading a count and setting one behave as in WordPress. <Ev scenario="wp_actions_read_and_write"/>

## Limits

An object, not an array: array functions throw a `TypeError`. Read counts with `did_action()`. <Ev source="ss:compat/hooks/breaks.json#L31-L36" hash="54b93d5ce67537aac4a63b115152329265e083c37e3e600e441dc4f2b8368703"/>

## Porting

Replacing `$wp_actions` doesn't reset the counts on SpeedySpec: the porting example below shows it. No compat scenario records it yet; it is listed in [the guide's findings](https://github.com/SpeedySpec/speedyspec-guide/blob/main/docs/hooks-findings.md) for speedyspec-server. Subtract an earlier `did_action()` instead.
