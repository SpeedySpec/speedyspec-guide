## Behaviour

Turns the native `verify_file_signature()`'s error into the `WP_Error` WordPress returns, with WordPress's data in WordPress's order, so `wp_error_added` fires as it does in WordPress. The caller's `$filename_for_errors` goes into the data as it was passed (an int stays an int); the file's base name is used when it is falsy.
