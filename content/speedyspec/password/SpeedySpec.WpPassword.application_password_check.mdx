## Behaviour

Checks an application password as `WP_Application_Passwords::check_password()` does. A `$generic$` hash is checked as a fast hash; any other hash goes to the bound `wp_check_password()` port, so a replacement checker answers for those too. <Ev source="ss:crates/speedyspec-wp-password-php/src/password.php#L38-L56" hash="819a673fac6ab12bed5a6452b16812ae7b9ec2e7f51c713f4c12099222b36fbe"/> <Ev test="speedyspec-wp-password::application::application_check_generic_uses_fast_hash"/> <Ev test="speedyspec-wp-password-php::php::application_check_uses_bound_checker"/>

WordPress's `WP_Application_Passwords` class stays WordPress's and doesn't call this function.
