## Behaviour

Coerces a password or hash as WordPress's own string functions do, before the facade hands it to a native function. It calls `strlen()` first, so PHP itself raises the deprecation for `null` (and carries on with `""`) and the `TypeError` for an array, naming `strlen()` as WordPress's do. <Ev source="ss:crates/speedyspec-wp-password-php/src/password.php#L5-L21" hash="d15a0d9544a1a6af0928c0baaa129380aacbffedf19f5ac2b0494bbf1113c2f4"/> <Ev test="speedyspec-wp-password-php::php::array_password_is_a_type_error"/> <Ev test="speedyspec-wp-password-php::php::null_arguments_deprecate_as_in_wordpress"/> Not for plugins.
