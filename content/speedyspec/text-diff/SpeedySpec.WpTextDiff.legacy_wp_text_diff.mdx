## Behaviour

WordPress 7.1's `wp_text_diff()` after `wp_parse_args()`: normalizes the whitespace, diffs the lines with `Text_Diff`, renders the rows with `WP_Text_Diff_Renderer_Table`, and wraps them in the table. The Rust implementation hands it the calls the native table doesn't cover (texts or titles that aren't strings, renderer properties passed as arguments), so their output is WordPress's own.
