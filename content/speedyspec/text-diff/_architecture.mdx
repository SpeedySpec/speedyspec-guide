## The crates

- **`speedyspec-wp-text-diff-contracts`**: the values a diff is asked for and answers with (`DiffOp`, `RowKind`, the table options and row labels), and the ports. <Ev source="ss:crates/speedyspec-wp-text-diff-contracts/src/lib.rs#L5-L17" hash="5e0f27682fd07b53b44b511915b860ad3d28e9272aaacf63254e016ce4447585"/>
- **`speedyspec-wp-text-diff`**: `wp_text_diff()` in Rust. `TextDiff` diffs lines with a `SequenceDiffer` and renders rows as `WP_Text_Diff_Renderer_Table` does; `HordeSequenceDiffer` is Horde's `Text_Diff_Engine_native`, ported line for line. String work (escaping, word and line splitting, byte counts) runs 16 bytes at a time where the CPU allows, with scalar twins the vector code is tested against. <Ev source="ss:crates/speedyspec-wp-text-diff/src/lib.rs#L5-L18" hash="0543adaa39499cf602d40eaf7c5d5f6fa85a9e9ada5c271054938ef45ae131ee"/> <Ev test="speedyspec-wp-text-diff-php::recorded::escaping"/> <Ev test="speedyspec-wp-text-diff-php::recorded::word_splitting"/>
- **`speedyspec-wp-text-diff-php`**: the PHP area. It binds WordPress's implementation, registers the port PHP may replace, and declares `wp_text_diff()`. <Ev source="ss:crates/speedyspec-wp-text-diff-php/src/lib.rs#L1-L16" hash="fa76d3293a2fa9af870fd8f93cc9be0cc717d8801c9f3a947d1767a168c05ec5"/>

## The contracts

- **`TextDiffer`** is `wp_text_diff()` itself, the pluggable function, bound under `SpeedySpec\WpTextDiff\TextDiffer`; the key is also the name of its PHP twin. Its one method, `diff(left, right, args)`, takes the three arguments as the caller passed them. <Ev source="ss:crates/speedyspec-wp-text-diff-contracts/src/port.rs#L11-L12" hash="20f0a8e277e619a8db44fe09bf06e9c9ee414b38d8b0cb3e69811d3f7d645173"/> <Ev source="ss:crates/speedyspec-wp-text-diff-contracts/src/port.rs#L46-L54" hash="fb9363c433603beb6c030f549a7e0e528fe9bc7a69bb1028fe79cfc8daf0cfaf"/>
- **`SequenceDiffer`** turns two token sequences into `DiffOp`s: Horde's engine for WordPress's output, or any other algorithm for callers that only need a correct diff.
- **`LineHtmlFilter`** is the `process_text_diff_html` filter; **`WhitespaceNormalizer`** is `normalize_whitespace()`, which belongs to text formatting.
- **`TextDiffHost`** is what WordPress's implementation reaches in PHP: `wp_parse_args()`, loading `wp-diff.php`, the translated row labels, WordPress's own classes for the calls Rust doesn't cover, and a fresh line filter per call. <Ev source="ss:crates/speedyspec-wp-text-diff-contracts/src/port.rs#L62-L79" hash="978294eef0e41b6f68a0f736ec3f0e4bd3e90d86ca8c420801115d69d31bdff2"/>

Text is bytes throughout, as PHP strings are.

## The use case

One query: **render the diff** (`WordPressTextDiffer::diff`). It parses the arguments, loads the renderer classes as WordPress does on every call, and renders the table in Rust when the texts and options are readable; otherwise it hands the call to WordPress's classes. <Ev source="ss:crates/speedyspec-wp-text-diff/src/port.rs#L111-L123" hash="a6757ee080b9931aceedc5a54e512055ca5d8b004b5e8096a06bfea527cd0577"/> With no `process_text_diff_html` callback, the filter is only counted, as WordPress counts it, and PHP is not entered. <Ev source="ss:crates/speedyspec-wp-text-diff-php/src/lib.rs#L15-L16" hash="dc65b99131641cf6ebf740c0eb48aa3ad9a05df1044e4508c71fdcc7fa6f7c07"/>

## Patterns

- **Ports and Adapters**: `TextDiffer` and `TextDiffHost`, with the PHP host and the PHP replacement as adapters.
- **Strategy** for the sequence differ (`SequenceDiffer`): Horde's engine, or another algorithm.
- **Registry** (the container) in place of a pluggable function; **Plugin** for a PHP replacement, wrapped by an **Adapter** (`PhpReplacement`).
- **Facade**: `text-diff.php` over the native function.

## How to change this

- **Replace `wp_text_diff()` from PHP:** implement `SpeedySpec\WpTextDiff\TextDiffer` in a class and bind the class name (not a closure), for one request or in `app.<id>.php.bindings`:

  ```php
  \SpeedySpec\Container\Container::getInstance()->bind(
      \SpeedySpec\WpTextDiff\TextDiffer::class,
      My_Plugin_Text_Differ::class
  );
  ```

  A replacement's exception reaches the caller unchanged. <Ev test="speedyspec-wp-text-diff-php::php::twin_exception_is_rethrown_unchanged"/>
- **Replace it from Rust:** bind your own `TextDiffer` with `bind_port` under `TEXT_DIFFER`, or build a `TextDiff` over another `SequenceDiffer`.
- **What must still pass:** WordPress's diff tests and the recorded cases. <Ev test="speedyspec-wp-text-diff-php::wordpress::wordpress_diff_tests_pass"/> <Ev test="speedyspec-wp-text-diff-php::recorded::wp_text_diff_cases"/>

## Calling it from Rust

A runtime feature that shows a revision's changes resolves the port, so a PHP replacement answers it too:

```rust
use speedyspec_container::Container;
use speedyspec_wp_text_diff_contracts::{TEXT_DIFFER, TextDiffer, Value};

/// The HTML table `wp_text_diff()` gives for two texts, or `None` when they are the same or the diff fails.
fn revision_table(container: &Container, old: &str, new: &str) -> Option<String> {
    let differ = container.make_port::<dyn TextDiffer>(TEXT_DIFFER).ok()?;
    match differ.diff(&Value::Str(old.into()), &Value::Str(new.into()), &Value::Null).ok()? {
        Value::Str(table) if !table.is_empty() => Some(table),
        _ => None,
    }
}
```
