## Behaviour

Holds the arguments `SpeedySpec\WpTextDiff\parse_args()` last returned, in its static `$args`, for a call whose parsed arguments can't reach Rust (a key that isn't UTF-8, a recursive array). `legacy_with_kept_args()` takes them and empties it.
