## Behaviour

Native: WordPress 7.2's function in PHP, with two changes. The `getimagesize_mimes_to_exts` default names the image types the media reader adds, and a local file's content type comes from fileinfo unless fileinfo files audio as video, or video as audio. <Ev source="ss:crates/speedyspec-wp-media-php/src/media.php#L284-L290" hash="f19079e80813de6b5943ed53cf605c2f1b950f1a537de79a2b0fcdb5c655a7b2"/> Over every corpus file, under its own name and renamed to `.jpg`, `.png`, `.mp3`, `.mp4`, `.mka`, `.txt` and `.pdf`, it matches the recording of WordPress 7.2-RC2 except where a difference is listed, and a listed difference that stops differing fails the test. <Ev test="speedyspec-wp-media-php::mime::filetype_checks_match_wordpress_except_listed_differences"/> <Ev test="speedyspec-wp-media-php::mime::every_mime_difference_is_still_needed"/> WordPress's own `mimeFunctions.php` tests pass against it. <Ev test="speedyspec-wp-media-php::wordpress::wordpress_media_tests_pass"/>

A PNG named `.jpg` gets `proper_filename`, an HTML file named `.mp3` is rejected, and a stream-wrapper path uses fileinfo's answer, as in WordPress. <Ev test="speedyspec-wp-media-php::php::png_named_jpg_gets_proper_filename"/> <Ev test="speedyspec-wp-media-php::php::html_named_mp3_is_rejected"/> <Ev test="speedyspec-wp-media-php::php::readable_stream_wrapper_uses_fileinfos_answer"/>

## Differences

- **Audio that fileinfo calls video.** When fileinfo and the extension name different kinds, the media reader reads the file, and the upload is accepted if it holds the kind the extension claims. The filter's `$real_mime` is then the reader's type (`audio/x-matroska`). The reader is never consulted for non-media types, when fileinfo already agrees, for stream-wrapper paths, or when it fails. <Ev source="ss:compat/media/DIFFERENCES.md#L109-L134" hash="fafa08906106408d414b996ff8e9ca81cb34a2282fecdc3a62fdae5eadade4c4"/> <Ev test="speedyspec-wp-media-php::php::audio_only_matroska_is_accepted"/> <Ev test="speedyspec-wp-media::content_mime::reader_never_overrides_non_media_fileinfo"/> <Ev test="speedyspec-wp-media-php::php::a_throwing_reader_leaves_fileinfos_answer"/>
- **Added formats.** The extensions SpeedySpec adds to the MIME list are accepted, and the added image types are renamed to their real extension, as WordPress does for the types it knows. <Ev source="ss:compat/media/DIFFERENCES.md#L59-L66" hash="5fa550f0d720b383cfa18ad15f467e68981dd19c98a6fdd7bee6eb9ab9a2b094"/> <Ev test="speedyspec-wp-media-php::php::filetype_and_ext_accepts_added_formats"/> <Ev test="speedyspec-wp-media-php::php::jxl_named_png_becomes_jxl"/>

WordPress 7.2's own rules are no longer differences: an MP4 or 3GP file that fileinfo calls `video/mp4` or `video/3gpp` is accepted under an `.mp3`-family extension, and a TrueType font may be `font/ttf` or `font/sfnt`. The recording is now 7.2-RC2's, which does the same, so the three listed MIME differences that came from comparing with 7.1.5 are gone. Where WordPress 7.2 already accepts such audio, `$real_mime` stays fileinfo's. <Ev source="ss:compat/media/DIFFERENCES.md#L130-L132" hash="9b0916d51c1dcb06579328e2d286b707393af23fabfc7dc721d63902b5647980"/> <Ev test="speedyspec-wp-media-php::php::real_mime_is_fileinfos_where_wordpress_accepts"/> <Ev test="speedyspec-wp-media-php::mime::every_mime_difference_is_still_needed"/>
