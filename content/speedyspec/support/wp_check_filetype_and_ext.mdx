## Behaviour

Native: WordPress 7.2's function in PHP, with two changes. The `getimagesize_mimes_to_exts` default names the image types the media reader adds, and a local file's content type comes from fileinfo unless fileinfo files audio as video, or video as audio. <Ev source="ss:crates/speedyspec-wp-media-php/src/media.php#L284-L290" hash="f19079e80813de6b5943ed53cf605c2f1b950f1a537de79a2b0fcdb5c655a7b2"/> Over every corpus file, under its own name and renamed to `.jpg`, `.png`, `.mp3`, `.mp4`, `.mka`, `.txt` and `.pdf`, it matches the recording of WordPress 7.1.5 except where a difference is listed, and a listed difference that stops differing fails the test. <Ev test="speedyspec-wp-media-php::mime::filetype_checks_match_wordpress_except_listed_differences"/> <Ev test="speedyspec-wp-media-php::mime::every_mime_difference_is_still_needed"/> WordPress's own `mimeFunctions.php` tests pass against it. <Ev test="speedyspec-wp-media-php::wordpress::wordpress_media_tests_pass"/>

A PNG named `.jpg` gets `proper_filename`, an HTML file named `.mp3` is rejected, and a stream-wrapper path uses fileinfo's answer, as in WordPress. <Ev test="speedyspec-wp-media-php::php::png_named_jpg_gets_proper_filename"/> <Ev test="speedyspec-wp-media-php::php::html_named_mp3_is_rejected"/> <Ev test="speedyspec-wp-media-php::php::readable_stream_wrapper_uses_fileinfos_answer"/>

## Differences

- **Audio that fileinfo calls video.** When fileinfo and the extension name different kinds, the media reader reads the file, and the upload is accepted if it holds the kind the extension claims. The filter's `$real_mime` is then the reader's type (`audio/x-matroska`). The reader is never consulted for non-media types, when fileinfo already agrees, for stream-wrapper paths, or when it fails. <Ev source="ss:compat/media/DIFFERENCES.md#L109-L134" hash="8a9893989e6aef157d17c1877436af1522801c3526ddc711d46ed401ede19541"/> <Ev test="speedyspec-wp-media-php::php::audio_only_matroska_is_accepted"/> <Ev test="speedyspec-wp-media::content_mime::reader_never_overrides_non_media_fileinfo"/> <Ev test="speedyspec-wp-media-php::php::a_throwing_reader_leaves_fileinfos_answer"/>
- **Added formats.** The extensions SpeedySpec adds to the MIME list are accepted, and the added image types are renamed to their real extension, as WordPress does for the types it knows. <Ev source="ss:compat/media/DIFFERENCES.md#L59-L66" hash="dfa8345b5217bd15fc49cf7474ffc5bae6e68a73ba8fde5db26352b022791ecf"/> <Ev test="speedyspec-wp-media-php::php::filetype_and_ext_accepts_added_formats"/> <Ev test="speedyspec-wp-media-php::php::jxl_named_png_becomes_jxl"/>
- **WordPress 7.2.** The function is trunk's, whose MP4 and 3GP audio rule and font types 7.1.5 doesn't have; WordPress 7.2's own tests run on it, while the recording it is compared with is 7.1.5's. Where WordPress 7.2 already accepts such audio, `$real_mime` stays fileinfo's. <Ev source="ss:compat/media/DIFFERENCES.md#L130-L132" hash="dd4f61ccd6f62e0f6eabd58e2b3b2537e9947c271095b6b8ed4a9ffdb6c226ef"/> <Ev test="speedyspec-wp-media-php::php::real_mime_is_fileinfos_where_wordpress_accepts"/>
