## Behaviour

Native. The global function resolves the `SpeedySpec\WpPassword\PasswordHasher` port on every call and hashes through it. <Ev source="ss:crates/speedyspec-wp-password-php/src/password.php#L88-L93" hash="2f9f91f89dd9f0b0c3097fec6f022ffb7dc03d3606a16d3f30b1c7a926a7375d"/> The signature, the `wp_hash_password_algorithm` and `wp_hash_password_options` filters in WordPress's order, and a set `$wp_hasher` behave as in WordPress. <Ev test="speedyspec-wp-password-php::php::signatures_match_wordpress"/> <Ev test="speedyspec-wp-password-php::php::filters_fire_in_wordpress_order"/> <Ev test="speedyspec-wp-password-php::php::wp_hasher_honoured"/> WordPress's `authPassword.php` tests pass against it, except the bcrypt-cost test listed as an expected failure. <Ev source="ss:crates/speedyspec-wp-password-php/tests/wordpress.rs#L19-L30" hash="bd25750da7897a1d9172599f83d9d1fda688ca4a230302c7e31a313d14c50e98"/> <Ev test="speedyspec-wp-password-php::wordpress::wordpress_password_tests_pass_but_divergences"/> The hashes it writes verify with PHP's own `password_verify()`. <Ev test="speedyspec-wp-password-php::php::round_trip_with_php"/>

## Differences

- **argon2id is the default.** Unless `wp_hash_password_algorithm` says otherwise, the hash is `$argon2id$`, through libsodium; WordPress writes `$wp$2y$`. Both verify with `wp_check_password()`. <Ev source="ss:crates/speedyspec-wp-password/src/hash.rs#L18-L20" hash="76079bff4cbe6cb27b64f55b51c76e0634e9cc044cb9265b39ae9dd5cc63fe27"/>
- **argon2 hashes the trimmed password**, as WordPress's bcrypt does; WordPress's argon2 hashes it untrimmed. <Ev test="speedyspec-wp-password::hash::default_is_argon2id_trimmed"/>
- **Cost limits.** Options above the site's limits are PHP's `ValueError`. <Ev test="speedyspec-wp-password::hash::costs_above_the_limits_are_value_errors"/> <Ev test="speedyspec-wp-password-php::php::php_bound_cost_limits_cap_hashing_and_checking"/>
- **The ignored-salt warning** has PHP's message but is an `E_USER_WARNING`. <Ev source="ss:crates/speedyspec-wp-password-php/src/lib.rs#L18-L20" hash="ed004c66cd0e97986f4603b4c9ce7d54083aabdc5d30810ed6482cf4cda7d436"/> <Ev test="speedyspec-wp-password-php::php::php_errors_match"/>

## Replacing it

Where WordPress lets a plugin declare `wp_hash_password()` first, SpeedySpec lets PHP bind its own class under `SpeedySpec\WpPassword\PasswordHasher` for the request; Rust callers then get it too. <Ev test="speedyspec-wp-password-php::php::php_override_replaces_default"/> <Ev test="speedyspec-wp-password-php::php::rust_callers_get_the_php_override"/> The [Passwords and crypto architecture](/speedyspec/architecture/password/) page shows the port, its crates and how to bind a replacement.
