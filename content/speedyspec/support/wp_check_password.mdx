## Behaviour

Native. The global function resolves the `SpeedySpec\WpPassword\PasswordChecker` port on every call. <Ev source="ss:crates/speedyspec-wp-password-php/src/password.php#L112-L123" hash="9cc46ab73c0ac0abef2e00300dd8f2a0ed093378ef5457f03137847668cf0a28"/> It replays the checks recorded from WordPress 7.1.5 (`compat/password/cases.json`), except the hash formats it rejects on purpose. <Ev test="speedyspec-wp-password-php::php::recorded_checks_replay"/> <Ev test="speedyspec-wp-password::check::check_replays_recorded"/> The `check_password` filter gets the user ID untouched, `$wp_hasher` is honoured, and WordPress's `authPassword.php` tests pass against it except the four phpass, MD5 and bcrypt-cost checks listed as expected failures. <Ev test="speedyspec-wp-password::check::filter_receives_user_id_untouched"/> <Ev test="speedyspec-wp-password-php::php::wp_hasher_honoured"/> <Ev source="ss:crates/speedyspec-wp-password-php/tests/wordpress.rs#L19-L30" hash="bd25750da7897a1d9172599f83d9d1fda688ca4a230302c7e31a313d14c50e98"/> <Ev test="speedyspec-wp-password-php::wordpress::wordpress_password_tests_pass_but_divergences"/>

## Differences

- **Old hashes never verify:** raw MD5 (32 characters or fewer), phpass `$P$`, `$2x$`, and the `crypt()`-only formats. The user resets their password. <Ev source="ss:crates/speedyspec-wp-password/src/check.rs#L1-L6" hash="939d673b6a99de42d1d1da17e05cd637dada4af41a4fe1ed779203df6cac388c"/> <Ev test="speedyspec-wp-password::check::md5_rejected_even_when_hash_matches"/> <Ev test="speedyspec-wp-password-bcrypt::vectors::refuses_2x"/>
- **Cost limits.** A stored hash above the site's limits never verifies, and its hash is never computed. <Ev test="speedyspec-wp-password::check::bcrypt_above_the_cost_limit_never_verifies_nor_runs"/> <Ev test="speedyspec-wp-password::check::argon2_above_the_cost_limits_never_verifies_nor_runs"/>

## Replacing it

Bind your own class under `SpeedySpec\WpPassword\PasswordChecker` for the request, where WordPress would have a plugin declare `wp_check_password()` first. <Ev test="speedyspec-wp-password-php::php::php_override_replaces_default"/> See the [Passwords and crypto architecture](/speedyspec/architecture/password/) page.
