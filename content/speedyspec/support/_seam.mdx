## How they are verified

WordPress's own PHPUnit tests for these functions run against the natives in the embedded PHP: `authPassword.php` and `wpRand.php` (all but five listed on purpose), `wpVerifyFastHash.php` (all but the phpass test), the diff tests, and the media tests `imageSize.php`, `mimeFunctions.php`, `wpGetMimeTypes.php` and `wpCheckFiletype.php`. <Ev test="speedyspec-wp-password-php::wordpress::wordpress_password_tests_pass_but_divergences"/> <Ev test="speedyspec-wp-crypto-php::wordpress::wordpress_crypto_tests_pass_but_phpass"/> <Ev test="speedyspec-wp-text-diff-php::wordpress::wordpress_diff_tests_pass"/> <Ev test="speedyspec-wp-media-php::wordpress::wordpress_media_tests_pass"/> Each area also replays what WordPress 7.2-RC2 recorded on PHP 8.5.12 (`compat/password`, `compat/crypto`, `compat/text-diff`, `compat/media`). None keeps a `scenarios.json` or `breaks.json`.

Verdicts: `wp_rand()`, `wp_generate_password()` and `wp_fast_hash()` work as in WordPress; the other 13 work with differences.

## Differences

- **Passwords.** argon2id is the default, so bcrypt hashes need a rehash; old hash formats (MD5, phpass and the `crypt()`-only ones) never verify; costs above the site's limits are refused. See the [Passwords and crypto seam](/speedyspec/password/).
- **Text diff.** Row labels are translated once per call, and a huge changed block throws. See the [Text diff seam](/speedyspec/text-diff/).
- **Media.** The image sniffer knows six more formats, the MIME list adds a row for each format the media reader reads, and `wp_check_filetype_and_ext()` is WordPress 7.2's, with the reader settling audio that fileinfo calls video. See the [Media seam](/speedyspec/media/).
