SpeedySpec's service container: Rust code and PHP code bind services by key and resolve them. It has no WordPress counterpart, so it appears only in the SpeedySpec API.

PHP reaches it through `SpeedySpec\Container\Container`, a singleton whose methods are backed by native functions; `bind()`, for one, calls `Native\bind()`. <Ev source="ss:crates/speedyspec-container-php/src/container.php#L16-L34" hash="337fbe47bea5d2a3e2c12fc6ef076ff89a23821a8344cfc89d5c4a199cef1a06"/> A service PHP binds can be made from PHP. <Ev test="speedyspec-container-php::php::php_binds_and_makes"/>

- A singleton is built once and shared; a plain binding builds a new value on each `make()`. <Ev test="speedyspec-container::container::singleton_is_shared"/> <Ev test="speedyspec-container::container::bind_is_not_shared"/>
- A scoped binding is shared until the request ends. <Ev test="speedyspec-container::container::scoped_is_shared_until_end_request"/>
- Ending a request removes everything registered during it. <Ev test="speedyspec-container::container::end_request_removes_request_lifetime_everything"/>
- The container tracks whether a key's current binding came from PHP rather than Rust, and a PHP object bound to a port resolves for Rust callers as that port. That is how a PHP plugin replaces an adapter, such as the Hooks seam's store. <Ev test="speedyspec-container::container::is_foreign_tracks_the_current_binding"/> <Ev test="speedyspec-container::container::bridged_value_resolves_as_its_port"/>
- Aliases resolve to their target, contextual bindings give each consumer its own value, tags return their services in tag order, and `extend()` decorates a binding, including an existing singleton. A circular dependency or an unknown key fails, naming it. <Ev test="speedyspec-container::container::alias_resolves_its_target"/> <Ev test="speedyspec-container::container::contextual_binding_gives_per_consumer"/> <Ev test="speedyspec-container::container::tagged_returns_in_tag_order"/> <Ev test="speedyspec-container::container::extend_decorates_and_applies_to_existing_singleton"/> <Ev test="speedyspec-container::container::circular_dependency_names_the_chain"/> <Ev test="speedyspec-container::container::unresolvable_names_the_key"/>
