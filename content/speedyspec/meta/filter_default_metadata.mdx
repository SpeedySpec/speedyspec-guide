## Behaviour

Native: the `FilterDefaultMetadata` query, hooked on `default_{$meta_type}_metadata` by [register_meta()](/speedyspec/meta/register_meta/). While WordPress is installing, or when the value is already set, it returns the value. Otherwise it gathers the key's defaults across the registered subtypes, takes a `''` subtype's default without asking for the object's subtype, and asks only when it must.
