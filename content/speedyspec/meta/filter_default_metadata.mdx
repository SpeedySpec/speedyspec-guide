## Behaviour

Native: the `FilterDefaultMetadata` query, hooked on `default_{$meta_type}_metadata` by [register_meta()](/speedyspec/meta/register_meta/). While WordPress is installing, or when the value is already set, it returns the value. Otherwise it gathers the key's defaults across the registered subtypes, takes a `''` subtype's default without asking for the object's subtype, and asks only when it must. A registered `null` default counts, as WordPress's `array_key_exists()` does. <Ev scenario="get-registered-default" area="metadata"/> <Ev scenario="get-registered-default-thing" area="metadata"/> <Ev scenario="get-default-while-installing" area="metadata"/> <Ev test="speedyspec-wp-meta::recorded::defaults_match_wordpress"/> <Ev test="speedyspec-wp-meta::registry::null_default_is_a_default"/> <Ev test="speedyspec-wp-meta::registry::unregistered_key_never_asks_for_the_subtype"/> <Ev test="speedyspec-wp-meta-php::wordpress::wordpress_meta_runs_pass"/>
