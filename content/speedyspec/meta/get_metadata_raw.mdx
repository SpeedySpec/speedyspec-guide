## Behaviour

Native: the `GetMetadataRaw` query. It runs the `get_{$meta_type}_metadata` short-circuit (with `$single`, index 0 of an array answer), then reads the object's cache entry, loading it on a miss, and returns `null` when nothing is stored. <Ev scenario="get-single-and-multiple-post" area="metadata"/> <Ev scenario="get-missing-key" area="metadata"/> <Ev scenario="get-invalid" area="metadata"/> <Ev scenario="get-short-circuit-single" area="metadata"/> <Ev scenario="get-cache-miss-exists-and-all" area="metadata"/> <Ev scenario="get-cache-miss-object" area="metadata"/> <Ev test="speedyspec-wp-meta-tests::use_cases::get_short_circuit_single_reads_index_zero"/> <Ev test="speedyspec-wp-meta-php::wordpress::wordpress_meta_runs_pass"/>
