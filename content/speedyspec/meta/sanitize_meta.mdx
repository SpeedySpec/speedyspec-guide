## Behaviour

Served by WordPress's PHP. The runtime worker links no meta crate, so PHP on SpeedySpec runs WordPress's own `meta.php`. <Ev source="ss:crates/speedyspec-php-runtime/Cargo.toml#L20-L55" hash="955f1ccec24cc11da3fa0826db96868561c6e6c3cdc55277b37b80c09b513508"/>

Its Rust port is phase 3 of the posts and meta port, which waits for the hooks, object cache and db contracts. The names of the filters it applies are already `MetaHookNames::sanitize`. <Ev source="ss:crates/speedyspec-wp-meta/src/hook_names.rs#L42-L45" hash="52eeeca55f97ce23a1ba2300ee3cccdb5574205c27990cdb87436e013a98f2d3"/>
